14 资本预算：回收期、NPV、IRR、PI

本篇覆盖《管理会计》（Managerial Accounting，讲师 Jeff / Finally Learn）资本预算章节的四讲：MA53 回收期法、MA54 用 Excel 算 NPV 与 IRR、MA55 用 BA II Plus 金融计算器算 NPV 与 IRR、MA56 获利指数与三指标对比。资本预算（Capital Budgeting）回答的问题是：要不要把一大笔钱投进一个长期项目（买机器设备、发起营销战役），指望未来若干年分批收回？讲师给出四个评价工具——回收期、NPV、IRR、PI——并用两组例题（Alpha/Suma 双项目、Kylo 单项目）把它们全部算了一遍。

一、先立框架：时间价值与现金流

1.1 引入：三年后收回本钱的项目，真的"安全"吗？

反直觉开场：两个项目摆在你面前——Alpha 花 $160,000，3.33 年回本；Suma 花 $240,000，要 4.25 年才回本。直觉告诉你选 Alpha：回本快，夜长梦少。但讲师用同一组数据算出：在 12% 的必要报酬率下，Alpha 的净现值是 −$2,617（拒绝），Suma 的净现值是 +$13,758（接受）。"安全"的回收期法给出了错误答案——因为它有两只眼睛都看不见的东西：回收期之后发生的一切现金流，以及钱的时间价值。这正是本篇要解决的：四个工具谁看见了什么、谁瞎在哪里。

1.2【呼应经济学】货币时间价值：资本成本就是机会成本

经济学里讲跨期选择时已经见过货币时间价值（Time Value of Money, TVM）：今天的一块钱比明年的一块钱值钱，因为今天的钱可以拿去生息。资本预算就是把这个原理用在企业投资决策上：未来的现金流必须折现（discount）回今天，才能和今天的投入放在同一把尺上比较。

折现用的利率叫必要报酬率（Required Rate of Return, RRR），它等于企业的资本成本（Cost of Capital）——而资本成本的本质正是经济学里的机会成本（Opportunity Cost）：这 $110,000 不投这个项目，也能投到别处赚 10%。所以"NPV > 0 才接受"的经济含义是：这个项目赚得比次优选择多，才真正创造了价值。这不神秘，就是机会成本思维的又一件马甲。

1.3 用现金流，不用净利润

反直觉点：Kylo 公司给了一份未来五年的预计利润表——但讲师第一件事是把它扔到一边：资本预算看的是现金流，不是净利润（Net Income）。为什么？因为折旧（Depreciation）是非现金费用：买设备的 $110,000 在第 0 年已经真金白银付出去了，之后每年的折旧只是账面上把这笔旧支出摊回来，并没有新的钱流出。于是每年的经营现金流（Operating Cash Flow, OCF）：

经营现金流 = 净利润 + 折旧（非现金费用加回）

Kylo 项目由此得到每年现金流入 $31,500（五年相同），第 0 年流出 $110,000。这个"净利润 + 折旧"的加回逻辑，和现金流量表间接法把折旧加回净利润求经营现金流是同一招——见 02 现金流量表。

现金流已定，工具任选：四个评价指标吃的是同一份现金流（第 0 年 −$110,000，第 1–5 年每年 +$31,500），区别只在"怎么看"这笔钱。下面逐个开箱。

二、回收期法（Payback Period）：简单，但瞎了一半

2.1 定义与计算

回收期（Payback Period, PP）回答一个问题：多久能把本钱收回来？若每年现金流相等，直接套公式：

回收期 = 初始投资 ÷ 年净现金流（Kylo：$110,000 ÷ $31,500 ≈ 3.49 年）

若每年现金流不等，就用累计现金流逐年追，并假设现金在年内均匀流入。讲师的例题（MA53）：DC 公司在 Alpha 与 Suma 之间二选一——

年份Alpha 当年现金流Alpha 累计Suma 当年现金流Suma 累计
0−$160,000−$160,000−$240,000−$240,000
1+$60,000−$100,000+$40,000−$200,000
2+$50,000−$50,000+$50,000−$150,000
3+$40,000−$10,000（还差 $10,000）+$60,000−$90,000
4+$30,000转正 → 回收期 3 + 10,000/30,000 = 3.33 年+$70,000−$20,000（还差 $20,000）
5+$20,000回收期法不再看+$80,000转正 → 回收期 4 + 20,000/80,000 = 4.25 年
6+$10,000回收期法不再看+$90,000回收期法不再看（大额流入被无视）

回收期越短越好：Alpha 3.33 年 < Suma 4.25 年，按回收期应选 Alpha。但注意最后一列：Suma 第 5、6 年还有 $80,000、$90,000 的大额流入，回收期法已经"翻篇"不看了——记住这一点，第三节会翻盘。

2.2 优点与致命缺点

  • 优点：① 极其简单，一句话能向任何人解释（"3.3 年回本"）；② 粗略度量流动性风险——回本越快，资金被占用、夜长梦多的时间越短，现金流紧张的小公司会看重这一点。
  • 致命缺点：① 完全忽略货币时间价值——第 1 年的一块钱和第 6 年的一块钱被当成同样的钱；② 完全忽略回收期之后的现金流——Alpha 第 4 年回本后该方法就不看了，Suma 第 5、6 年的 $170,000 大额流入被整个无视。两个缺点叠加，回收期法不能作为首选决策工具，只能当粗筛。

三、净现值（NPV）：把一切折回今天

3.1 定义与判定规则

净现值（Net Present Value, NPV）：把项目未来每一笔现金流按必要报酬率折现到今天，加总，再减去初始投资：

NPV = 未来现金流现值合计 − 初始投资　→　NPV > 0 接受，NPV < 0 拒绝

NPV > 0 的含义：项目收益率超过必要报酬率，除了赚回资本成本还有剩余——真正创造价值。NPV 是两个"首选方法"之一，因为它同时治好了回收期法的两个瞎点：考虑时间价值，且看见全部现金流。

3.2 Excel 实操与 NPV 函数陷阱（Kylo 例题）

讲师强烈推荐用 Excel 或金融计算器，而不是教科书附录的利率表（"现实世界里没人那么算"）。以 Kylo 项目为例（必要报酬率 10%）：

Excel NPV 函数陷阱：=NPV(10%, 第1年:第5年现金流) 只把第 1 年起的现金流折现，得出 $119,410——它不包含第 0 年的初始投资（那笔钱本来就在"今天"，无需折现）。真正的净现值要再手动减去投资：NPV = 119,410 − 110,000 = $9,409。把第 0 年也塞进 NPV 函数是初学者最常见的错误，会多折现一次初始投资。

图 1 解读：第 1–5 年名义现金流都是 $31,500（蓝柱等高），但折现到今天的现值（橙柱）逐年缩水——第 1 年 $28,636，第 5 年只剩 $19,559。五年现值合计 $119,410，减去第 0 年投入的 $110,000（图外），得 NPV = +$9,409 → 接受。这张图就是"货币时间价值"的直观形状：同样的钱，越晚到越不值钱。

复算验证：31,500 × 年金现值系数（10%，5 年）= 31,500 × 3.7908 ≈ $119,410；119,410 − 110,000 = $9,409，与讲师一致。

3.3 Alpha 与 Suma：NPV 推翻回收期的结论

把 MA53 那两个项目放到 12% 必要报酬率下重算（MA54、MA55），回收期的答案被整个翻转：

指标Alpha（投入 $160,000）Suma（投入 $240,000）结论
回收期3.33 年 ✓ 更短4.25 年回收期法选 Alpha
NPV（12%）−$2,617+$13,758 ✓首选方法都选 Suma
IRR11.24% < 12%13.74% > 12% ✓

Suma 的现金流"前小后大"，回收期法看不见后半程的 $80,000、$90,000；NPV 全看见了——尽管要折现，后期的钱仍然值钱到足以翻盘。若两个项目互斥且只能选一个，以 NPV 为准。

四、内含报酬率（IRR）：让 NPV 恰好为零的折现率

4.1 定义与判定规则

内含报酬率（Internal Rate of Return, IRR）是使 NPV 恰好等于零的那个折现率——可以理解为项目自身的"真实收益率"。判定规则：

IRR > 必要报酬率 → 接受；IRR < 必要报酬率 → 拒绝

逻辑上与 NPV 完全同构：IRR > 必要报酬率 ⟺ 用必要报酬率折现的 NPV > 0。所以单一项目的接受/拒绝决策上，NPV 与 IRR 永远给出相同信号。

4.2 例题与工具：Excel、BA II Plus

Kylo 项目：Excel 里 =IRR(第0年:第5年全部现金流)——注意 IRR 函数与 NPV 函数相反，必须包含第 0 年的负投资——得 IRR = 13.29% > 10% → 接受。复算验证：令 31,500 × 年金系数 = 110,000，系数 = 3.4921，对应折现率约 13.3%，与讲师一致。由于 NPV(10%) > 0，我们事先就知道 IRR 必然大于 10%，计算只是给出精确值。

BA II Plus 计算器步骤框（以 Alpha 为例，MA55）：
  1. CF 键进入现金流模式 → 2nd CLR WORK 清空旧数据；
  2. CF0 = −160,000（输入数字后按 +/− 变负）ENTER ↓；
  3. C01 = 60,000 ENTER ↓（频率 F01 留 1），依此录入 50,000 / 40,000 / 30,000 / 20,000 / 10,000；
  4. 按 NPV → 输入 I = 12 ENTER ↓ → CPT → 得 −2,617（拒绝）；
  5. 按 IRR → CPT → 得 11.24%。Professional 版继续按 ↓ 还能直接算出回收期 PB = 4.25（对 Suma）。
Excel 与计算器结果完全相同（Alpha：NPV −$2,617、IRR 11.24%；Suma：NPV +$13,758、IRR 13.74%）。BA II Plus 是 CFA 等考试允许携带的机型，值得练熟。

IRR 的优点：用一个百分数表达项目收益率，沟通直观（"这项目赚 13.29%"），不必先选定折现率就能看出项目大概处于什么水平。缺点：① 手算几乎不可能，必须借助工具；② 它隐含假设中间收到的现金流能按 IRR 本身再投资——13.29% 的再投资收益率往往不现实（NPV 假设按必要报酬率再投资，更保守合理）；③ 现金流符号多次变号时可能出现多个 IRR，互斥项目比较时也可能与 NPV 冲突（此时以 NPV 为准）。

五、获利指数（PI）：每投 $1 收回多少

5.1 定义与判定规则

获利指数（Profitability Index, PI）把 NPV 改写成比率形式：

PI = 未来现金流现值合计 ÷ 初始投资　→　PI > 1 接受，PI < 1 拒绝

Kylo 项目：PI = 119,410 ÷ 110,000 = 1.09。解读："每投入 $1，按现值收回 $1.09"。由于 PI 的分子减去分母就是 NPV，所以 PI > 1 ⟺ NPV > 0——两者给出完全相同的接受/拒绝信号。

5.2 PI 的独特优势：比较不同规模的项目

既然 PI 与 NPV 同信号，为什么还要它？因为 NPV 是绝对金额，受项目规模影响：一个投 $10,000,000 赚 NPV $50,000 的项目，和一个投 $100,000 赚 NPV $20,000 的项目，哪个"效率"高？NPV 答不上来，PI 可以：前者 PI = 1.005，后者 PI = 1.20——后者每美元投资的产出效率高得多。当资金有限（资本配给）、要在多个项目间排优先级时，PI 是比 NPV 更好的排序工具。缺点是它丢失了绝对规模信息：PI 1.20 的小项目创造的总财富可能仍少于 PI 1.005 的大项目。

5.3 敏感性演示：必要报酬率 10% → 15%，三指标全部翻转

NPV/IRR/PI 都依赖必要报酬率，而它只是企业的估计值。把 Kylo 项目的必要报酬率从 10% 提到 15%（资金更贵或风险更高），三个指标整齐划一地翻转：

指标必要报酬率 10%必要报酬率 15%判定翻转
未来现金流现值$119,410$105,593折现率↑ → 现值↓
NPV+$9,409 → 接受−$4,407 → 拒绝正转负
IRR（不随折现率变）13.29% > 10% → 接受13.29% < 15% → 拒绝超过变为不足
PI1.09 → 接受0.96 → 拒绝"每 $1 收回 $1.09"变成"每 $1 只收回 $0.96"

复算验证：15% 下 PV = 31,500 × 3.3522 ≈ $105,593；NPV = 105,593 − 110,000 = −$4,407；PI = 105,593 ÷ 110,000 ≈ 0.96，均与讲师一致。IRR 本身不变（它是项目的内在属性），变的是它与必要报酬率的相对位置。三指标同进同退，再次印证它们共享同一个折现内核。
