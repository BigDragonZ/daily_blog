05 产品成本基础：COGM/COGS 与成本流转

本篇覆盖《管理会计》（Managerial Accounting，讲师 Jeff / Finally Learn）Ch15 导论章的 MA21–MA26 与 Ch16 的 MA30 共七讲：产品成本 vs 期间成本、产品成本三要素（DM/DL/MOH）、直接材料耗用量、制造成本（COGM）与销货成本（COGS）的编制、成本在三个存货账户间的流转，以及反向推算与期末余额实战。上一篇 P01 已经把成本按"工厂内/外"分成了产品成本与期间成本，本篇回答它留下的悬念：产品成本进了存货之后，什么时候、沿着什么路径才变成利润表上的费用。

一、产品成本 vs 期间成本：费用化的时点之争

1.1 引入：仓库里没卖掉的存货，今年不算费用

反直觉开场：家具厂今年花 10 万美元买木料、付工钱，到了年底，一半家具还躺在仓库里没卖掉。直觉说"钱都花了，当然是今年的费用"——会计说不。没卖掉的那部分成本不进入今年的利润表，而是作为存货"躺"在资产负债表上（它是一项资产），等未来售出的那一年才变费用。花钱的时点与费用化的时点被刻意拆开——这个"何时算费用"的问题，正是管理会计与财务会计必须达成共识的分水岭：存货计价高一点，今年利润就高一点，所以外部报表规则（GAAP/IFRS）对此管得最严。

规则本身一句话就能说完：产品成本（Product Cost）先计入存货（资产），产品售出时才转为销货成本（Cost of Goods Sold, COGS）费用；期间成本（Period Cost）不与产品挂钩，发生当期直接费用化（销售费用、管理费用、研发费用等）。判断口诀仍是 P01 那句："这事发生在工厂里吗？"（Did it happen in the factory?）

1.2 一字之差定归属（MA24：家具厂十二项成本）

同样是折旧、同样是用品，"factory"与"office"一字之差，归属天差地别。家具厂（造桌椅）的 12 项成本逐项分类，先自己判断再对照：

成本项目分类判断要点
家具用木料（Wood）产品成本 — DM进入产品实体的主要材料
家具用胶水（Glue）产品成本 — MOH间接材料：不值得逐滴追踪到每件产品
造家具工人工资（Wages）产品成本 — DL手直接接触产品（hands on the product）
工厂水电费产品成本 — MOH出现 "factory" 字样 → 产品成本；非料非工 → MOH
工厂设备折旧产品成本 — MOH工厂资产折旧是最经典的制造费用
工厂耗材（Factory supplies）产品成本 — MOH维持工厂运转，但金额不值得追溯 → 间接材料
工厂经理薪资产品成本 — MOH间接人工：在工厂但不亲手做产品
广告费期间成本 — 销售费用为卖产品而发生，不造产品
销售部门薪资与佣金期间成本 — 销售费用销售职能，当期费用化
办公用品（Office supplies）期间成本 — 管理费用"office" → 行政管理
办公设备折旧期间成本 — 管理费用与工厂设备折旧对照：一字之差，产品变期间
CFO（首席财务官）薪资期间成本 — 管理费用高管与造产品无关；注意它连 MOH 都不是

优点与缺点：产品/期间二分法让存货计价与利润确认清晰衔接（本篇后半的 COGM/COGS 全靠它）；缺点是所有"工厂内但不可追溯"的成本都被扫进 MOH 这个杂物桶，归集粗糙会扭曲产品成本——这正是 P08 作业成本法要修的问题。

二、产品成本三要素：DM / DL / MOH

2.1 三要素与三个存货账户

制造业企业的产品在报表上要经过三个存货阶段：原材料（Raw Materials, RM）→ 在产品（Work in Process, WIP，已开工未完工）→ 产成品（Finished Goods, FG，完工待售）。以木制家具为例：木料是原材料，锯开打磨到一半的是在产品，组装完毕可以卖的是产成品。

把产品"造"出来的成本恰有三类，合称产品成本（也叫制造成本，Manufacturing Costs）：

  • 直接材料（Direct Materials, DM）：进入产品实体、值得逐件追溯的材料，如木料；
  • 直接人工（Direct Labor, DL）：亲手加工产品的工人薪酬，如木工；
  • 制造费用（Manufacturing Overhead, MOH，也叫 Factory Overhead, FOH）：其余一切工厂成本——间接材料（胶水）、间接人工（工厂主管、维修、保洁）、设备折旧、工厂水电、工厂财产税。
MOH 的本质是"杂物桶"：凡发生在工厂里、但既不是直接材料也不是直接人工的成本，统统倒进 MOH。它还分两层：实际制造费用按发生数归集，分摊到产品上的制造费用用预定分配率估算（MA30 的 70% 分配率见第六节；估计与实际的差异即"多分摊/少分摊"，P06 分批成本法详讲）。

三、直接材料耗用量：原材料账户的流出

3.1 引入：买了≠用了

反直觉开场：今年采购了 $144,800 的木料，计入产品成本的材料就是 $144,800 吗？不是——年初仓库里还有去年剩下的料，年底仓库里也还有没用完的料。采购是流入，耗用才是流出，两者之差被期初、期末库存吸收。

材料是资产账户，借方记增加、贷方记减少，于是：

耗用直接材料（DM Used）= 期初材料 + 本期采购 − 期末材料

3.2 例题（MA22，Samco 公司）：公式法与 T 型账户

已知：期初材料 $5,100，本期采购 $144,800，期末材料 $8,500。

  • 公式法：可供使用的材料 = 5,100 + 144,800 = $149,900；减去没用完的期末 $8,500 → 耗用直接材料 = $141,400。
  • T 型账户法：把同一笔账画成 T 型账户，左右必相等——它的真正威力在反向推算：若未知数换成期初余额或采购额，把已知三项摆进去一减即得（像解谜）。
原材料（Raw Materials）
借方（增加）贷方（减少）
期初余额　5,100耗用转出（→WIP）　141,400
本期采购　144,800期末余额　8,500
合计　149,900合计　149,900

这 $141,400 离开原材料账户后的去向是在产品账户，会计分录为：借：在产品（WIP）141,400　贷：原材料 141,400。成本没有消失，只是换了个资产账户继续"躺"着——这是理解全篇的关键一步。

四、制造成本（COGM）：在产品账户的流出

4.1 公式与"总制造成本"

在产品账户是生产的"搅拌碗"：期初 WIP（去年没做完的）加上今年投入的 DM、DL、MOH，是本期经手的全部成本；减去期末还没做完的（期末 WIP），剩下的就是完工产品的成本——制造成本（Cost of Goods Manufactured, COGM）：

COGM = 期初 WIP +（DM 耗用 + DL + MOH）− 期末 WIP
其中 DM + DL + MOH 合称总制造成本（Total Manufacturing Costs），与"总产品成本"是同义词。

4.2 例题（MA23，承 MA22 数据）：编制 COGM 计算表

沿用 Samco：耗用直接材料 $141,400（上节已算）、直接人工 $97,000；制造费用由间接人工、折旧、水电加总为 $46,200；期初 WIP $13,000、期末 WIP $10,000。

  • 总制造成本 = 141,400 + 97,000 + 46,200 = $284,600；
  • 在产品总成本 = 284,600 + 13,000 = $297,600（本期经手的一切）；
  • COGM = 297,600 − 10,000 = $287,600（本期真正完工的部分）。

一个题目若同时问"总制造费用、总制造成本、在产品总成本、COGM"四个数，不用慌——它们全是 COGM 计算表的内置小计，把表编完四个答案自然浮现。COGM 转出时的分录：借：产成品　贷：在产品。

T 型账户验证（讲师自用的速算法，与长格式结果一致）：借方 期初 13,000 + DM 141,400 + DL 97,000 + MOH 46,200 = 297,600；贷方 期末 10,000 + COGM 287,600 = 297,600。✓

五、销货成本（COGS）：产成品账户的流出

5.1 公式与"制造业版 COGS"

完工产品进入产成品账户后，再套用同一个"期初 + 流入 − 期末 = 流出"模板：

COGS = 期初 FG + COGM − 期末 FG

回忆商业企业的 COGS = 期初存货 + 购货 − 期末存货——制造业只是把"购货"换成了"自己造出来的 COGM"，结构完全同构。COGS 是整条成本流转链上第一个、也是唯一一个费用：此前的每一步，成本都只是在资产负债表内部的三个存货账户之间搬家。

5.2 全流程例题（MA25）：从期初材料一路算到 COGS

某制造商本年数据：期初材料 $2,300、材料采购 $97,400、期末材料 $4,100；直接人工 $122,400；工厂相关间接成本（间接人工、工厂设备折旧、工厂水电）合计 $48,000——注意要剔除混在题里的管理费用、销售费用与利息费用（它们是期间成本，永远不进这道流水线）；期初 WIP $8,500、期末 WIP $9,700；期初 FG $6,400、期末 FG $9,100。三段计算连成一张计算表：

六、成本流转全景：RM → WIP → FG → COGS

6.1 一张图看全：三个存货账户 + 一个费用出口

图 1 解读：蓝色方框是资产负债表上的三个存货账户（资产），绿色是本期注入的成本流（采购、直接人工、制造费用），橙色的 COGS 是整张图里唯一的费用——它流向利润表；棕色的期间成本当期直接费用化，从不进入这条流水线。每条箭头对应一笔会计分录（如"耗用直接材料"即 借 WIP / 贷 原材料）。讲师提醒这张图"初看像一盘意大利面"，但只要记住跟着箭头走，每个账户都是同一个公式：期初 + 流入 − 期末 = 流出。优点：全景、防漏项，任何缺数题都能对号入座；缺点：把 MOH 画成一条干净箭头，掩盖了它"先实际归集、再按分配率估算分摊"的两层结构（P06 展开）。

6.2 反向推算（MA26）：缺什么，就用公式倒挤什么

这类题不能盯着数字发呆，必须套计算表格式倒挤。两道实战：

  • Juliet 公司：已知总产品成本 $302,500、DL $87,400、MOH $113,000 → DM = 302,500 − 87,400 − 113,000 = $102,100；已知在产品总成本 $344,700 → 期初 WIP = 344,700 − 302,500 = $42,200；已知 COGM $287,300 → 期末 WIP = 344,700 − 287,300 = $57,400。
  • Kilo 公司：已知总制造成本 $26,400、DM $12,600、MOH $6,700 → DL = 26,400 − 12,600 − 6,700 = $7,100；期初 WIP $7,200 → 在产品总成本 = 26,400 + 7,200 = $33,600；期末 WIP $4,400 → COGM = 33,600 − 4,400 = $29,200。

6.3 三个存货账户期末余额（MA30，Oscar 公司，T 型账户实战）

分批成本法下的完整演练：已知期初余额（材料 $8,200、WIP $7,100、FG $6,400）、本期采购 $22,800、耗用材料 $27,400、直接人工 $34,500、MOH 预定分配率 = 直接人工的 70%、COGM $47,400、COGS $38,900。逐账户套用"期初 + 流入 − 流出 = 期末"：

  • 原材料：8,200 + 22,800 − 27,400 = $3,600（没用完的留下）；
  • 在产品：分摊 MOH = 34,500 × 70% = $24,150；期末 WIP = 7,100 + 27,400 + 34,500 + 24,150 − 47,400 = $45,750；
  • 产成品：6,400 + 47,400 − 38,900 = $14,900。
彩蛋（P06 预告）：本期实际 MOH 为 $24,800，而分摊进产品的只有 $24,150——实际 > 分摊的 $650 称为少分摊制造费用（Underapplied Overhead），期末通常直接转入 COGS 调整；反之则为多分摊（Overapplied）。估算很少完美，小额差异是常态。

6.4 收尾对比：产品成本 vs 期间成本

维度产品成本（Product Cost）期间成本（Period Cost）
判断口诀发生在工厂内发生在工厂外（销售/办公/研发）
举例木料、造家具工人工资、工厂设备折旧、工厂经理薪资、胶水广告费、销售佣金、办公设备折旧、CFO 薪资
费用化前落脚资产负债表：RM → WIP → FG（资产）不停留，直接进利润表
费用化时点产品售出时转为 COGS发生当期即费用
报表位置售出前进资产负债表；售出后进利润表 COGS利润表：销售费用 / 管理费用 / 研发费用
优点与存货计价、利润确认无缝衔接，匹配收入与成本处理简单，无需归集分摊
缺点MOH 杂物桶归集粗糙会扭曲单位成本（P08 ABC 修）不提供产品维度的成本信息

本篇思想链路：核心问题（花出去的成本什么时候才算费用？）→ 简化模型（工厂内→产品成本→进存货；工厂外→期间成本→当期费用；三个存货账户各套"期初＋流入−期末＝流出"）→ 推导（DM Used → COGM → COGS 三段计算表首尾相接）→ 实际应用（Samco 的 COGM 编制、全流程 COGS、Juliet/Kilo 倒挤、Oscar 期末余额）→ 局限性（MOH 是估算出来的，分配率失真则单位成本失真；T 型账户是万能备胎但考试要按计算表格式书写）。
