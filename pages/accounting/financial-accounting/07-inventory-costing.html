07 存货计价：FIFO/LIFO/加权平均

本篇覆盖《财务会计》（Financial Accounting）Lesson 7 的 14 讲（7.2–7.15；7.1 缺号，本章导论由本篇按课程逻辑补齐）。核心问题只有一个：同款商品分批进货、进价各不相同时，卖出一件该把哪笔成本转进销售成本？答案是四种合法的成本流转假设（Cost Flow Assumption）——个别计价法（Specific Identification）、先进先出法（First-In, First-Out, FIFO）、后进先出法（Last-In, First-Out, LIFO）、加权平均法（Weighted Average）——外加定期/永续两种盘存时点、成本与可变现净值孰低的减记规则，以及存货周转率与销售天数两个比率。所有例题均在定期盘存制下演算，数字已逐一复算。

一、引入：同一件商品，四种合法的销货成本

1.1 反直觉开场：地球仪该记 $15 还是 $16？

场景：你的店年初库存两个地球仪，每个进价 $15，售价 $20。卖得很好，于是向供应商补货四个——但供应商涨价了，新货每个 $16。你决定自己消化涨幅，售价仍保持 $20。此时存货账户里躺着 2 × $15 + 4 × $16 = $94。这时一位顾客进店，买走一个地球仪。问题：从存货转入销售成本（Cost of Goods Sold, COGS）的金额该是多少？

直觉说"看他拿走的是哪件"——但会计上这笔分录（借：COGS，贷：存货）的金额有四种合法答案：可以是 $15（先进先出）、$16（后进先出）、$15.67（加权平均，94 ÷ 6）、或者那件被拿走商品的真实成本 $15 或 $16（个别计价）。同一家店、同一件商品、同一笔销售，仅仅因为选用了不同的成本核算方法（Costing Method），利润表上的利润就不一样。本章的任务就是搞懂这四种答案各自的规则、适用场景与后果。

1.2 成本流转 ≠ 实物流转

理解本章的钥匙是一条总原则：账面上的成本流转不必与商品的实物流转一致。顾客明明拿走了那个进价 $16 的新地球仪，账上照样可以把 $15 费用化——完全合规。买牛奶是最好的类比：顾客总会从货架深处掏出保质期最晚（通常也是最晚进货、成本最高）的那瓶，把早几天到的旧货留在前面；但商店用 FIFO 记账时，假定卖掉的是"最先进来"的那瓶的成本。实物流是顾客行为，成本流是会计政策，两者各走各的。因此方法选择的本质不是"猜顾客拿了哪件"，而是：把可供销售的总成本，在"已售出（费用）"与"未售出（资产）"之间做分配。

1.3 分配框架：可供销售商品成本的一分为二

缺失提示：本课程 Lesson 7 从 7.2 讲起，7.1 缺号。按前后文逻辑，7.1 应为本章导论，其核心是可供销售商品成本（Cost of Goods Available for Sale, COGAS）框架：可供销售商品成本 = 期初存货 + 本期采购，而这笔总额在期末必然恰好分成两块——已售出部分进 COGS（利润表），未售出部分留作期末存货（资产负债表），即 COGAS = COGS + 期末存货。四种计价方法的唯一分歧就是这条切线画在哪里。

图 1 解读：以本章综合例的数据为例——期初存货 2,000 件（@$40）加两次采购共 16,000 件，COGAS = $744,000。期末盘点发现售出 9,000 件、剩 7,000 件，于是 $744,000 必须切成 COGS 与期末存货两块：FIFO 切法是 $394,000 / $350,000，LIFO 切法是 $444,000 / $300,000，加权平均切法是 $418,500 / $325,500。三种切法的总和永远是 $744,000——COGS 多分一点，期末存货就少留一点，利润与资产此消彼长。这个零和结构是本章所有结论的根源。

1.4 四种方法总览

方法成本流转假设适用商品一句话记忆
个别计价法（Specific Identification）追踪每件商品的真实成本，卖哪件转哪件高价、低销量、可辨识（汽车、珠宝、房屋）唯一与实物流永远一致的方法
先进先出法（FIFO）最早购入的成本最先转出低价值、高销量、同质化、难以逐件追踪的商品（杂货、牛奶、打印机）期末存货最接近现行市价
后进先出法（LIFO）最近购入的成本最先转出通胀期 COGS 高、利润与税负低；IFRS 禁用
加权平均法（Weighted Average）不区分批次，全部摊成同一个平均单位成本结果居中（加权而非简单平均）

二、个别计价法：唯一与实物流匹配的方法

2.1 规则与适用边界

个别计价法（Specific Identification）直接把售出商品的真实成本转入 COGS——顾客买了 4 号地球仪，就把 4 号那颗的 $16 转出去，其余成本概不关心。它是四种方法中唯一成本流与实物流始终一致的方法（FIFO/LIFO 只是偶尔巧合一致）。代价是必须能逐件追踪，因此适用条件有四条：高价值（汽车、珠宝、船只、房屋）、低销量（汽车经销商一天卖不出几辆，追得过来）、商品独特可辨识（每颗生菜贴着同一个 UPC 码，无从区分；每辆车有唯一的车辆识别码（VIN）、每套房有唯一门牌）、易于追踪（序列号、VIN、地址等标识）。

2.2 配套例题：A 公司批发机器（7.4）

A 公司从本地制造商购入五台机器转售，一月份售出其中两台——机器 B 和机器 D。用个别计价法求 COGS、期末存货与毛利润，并编制分录：

机器成本售价状态与归属
A$12,500$20,000未售 → 期末存货
B$12,800$21,000已售 → COGS
C$13,500$22,500未售 → 期末存货
D$14,350$24,000已售 → COGS
E$15,800$26,000未售 → 期末存货
合计（COGAS）$68,950——

逐步复算：① COGS = 售出两台的实际成本 = 12,800（B）+ 14,350（D）= $27,150。② 期末存货 = 未售三台 = 12,500 + 13,500 + 15,800 = $41,800；验证：68,950 − 27,150 = 41,800 ✓。③ 销售收入 = 21,000 + 24,000 = $45,000，毛利润 = 45,000 − 27,150 = $17,850。④ 分录两笔：记录销售——借：现金 $45,000，贷：销售收入 $45,000；结转成本——借：销售成本 $27,150，贷：存货 $27,150。

优点：计量最精确，成本与实物一一对应，无假设成分。缺点：①只适用于高价低量商品，一天卖 250 加仑牛奶的杂货店根本追不起；②易被用来"挑成本"操纵利润——管理者想抬高利润就卖低成本那件、想压利润避税就卖高成本那件，利润成了可以"点单"的选择，这是它最大的治理软肋。

三、定期 vs 永续：与计价方法正交的另一条轴

FIFO/LIFO/加权平均回答的是"转多少"，定期盘存制（Periodic Inventory System）与永续盘存制（Perpetual Inventory System）回答的是"何时转"——两条轴可以自由组合，同一组数据在不同组合下可能算出不同答案：

  • 定期盘存制：平时销售只记收入分录，不碰成本；到期末（月末/年末）一次性计算并把成本从存货转入 COGS。工作量小，但期内存货账面与实物脱节；
  • 永续盘存制：每次销售立即做两笔分录（一笔收入、一笔成本），存货与 COGS 随时是最新的。工作量大，信息也更及时准确。
一致性原则：盘存制度与计价方法一旦选定，不应跨期随意更换（今年定期明年永续、今年 FIFO 明年 LIFO，都破坏可比性——可比性正是 Lesson 1 讲的报表质量特征之一）。本章全部例题均为定期盘存制：先把整个期间的 COGAS 汇总，期末再按成本流转假设一次性切分。

四、先进先出法（FIFO）：老成本先走，新成本留下

4.1 规则与直觉

先进先出法（First-In, First-Out, FIFO）假定最先购入存货的成本最先转入 COGS，无论顾客实际拿走哪件。回到地球仪：顾客拿走 4 号（真实成本 $16），FIFO 照样把最早入库那批的 $15 费用化，存货账户剩 $79。再卖一件，仍用 $15（第二批次的 $15 尚未用完）；卖到第三件才轮到 $16。效果：COGS 装着最老的成本，期末存货装着最新的成本——所以 FIFO 下资产负债表上的存货最接近现行重置市价，这是它报表质量上的招牌优点。

4.2 配套例题：简例（7.7）

A 公司五台机器（政策强制 FIFO，即使机器可辨识也不许用个别计价），每台售价 $18,000，五月售出两台。FIFO 只看入库顺序：最早的两台是 A（$12,600）和 B（$12,800），于是 COGS = 12,600 + 12,800 = $25,400；期末存货 = 68,950 − 25,400 = $43,550（恰为剩余三台 C、D、E 的成本之和）；收入 = 2 × 18,000 = $36,000，毛利润 = 36,000 − 25,400 = $10,600。分录：借现金 $36,000 / 贷销售收入 $36,000；借销售成本 $25,400 / 贷存货 $25,400。对比个别计价例：同样卖两台机器，方法不同，COGS 与毛利全变。

4.3 配套例题：综合例（7.8，定期盘存）

A 公司全年逐笔记录采购与销售的数量，但到期末才做成本计价（定期制）。数据如下（销售行没有单位成本——这正是要算的）：

日期事项数量单位成本批次成本
7月1日期初存货2,000$40$80,000
7月5日售出1,000——
7月13日采购6,000$44$264,000
7月17日售出3,000——
7月25日采购8,000$50$400,000
7月27日售出5,000——
可供销售合计（COGAS）16,000—$744,000

五步法（FIFO）：① 总销量 = 1,000 + 3,000 + 5,000 = 9,000 件。② 按期入库排序：7/1（2,000@40）→ 7/13（6,000@44）→ 7/25（8,000@50）。③ COGAS = 80,000 + 264,000 + 400,000 = $744,000。④ 为 9,000 件销量从最早批次逐层分配：先吃 7/1 全部 2,000 件（$80,000），再吃 7/13 全部 6,000 件（$264,000），还差 1,000 件从 7/25 批取（$50,000）——COGS = 80,000 + 264,000 + 50,000 = $394,000。⑤ 期末存货 = 744,000 − 394,000 = $350,000；验证：只剩 7/25 批的 7,000 件 × $50 = $350,000 ✓。学习纪律：初学分五步慢算，别走捷径——数字搞混几乎都发生在跳步时。

优点：期末存货按最新成本计价，资产负债表最贴近现值；实物流常与假设天然吻合（食品、药品本来就要先卖旧货），是实务中采用最广的方法。缺点：通胀期 COGS 用的是过时的便宜老成本，利润被"虚增"，所得税跟着多缴；利润表上老成本对新售价，配比质量打折。

五、后进先出法（LIFO）：新成本先走，税单变薄

5.1 规则与动机

后进先出法（Last-In, First-Out, LIFO）与 FIFO 镜像相反：假定最近购入的成本最先转入 COGS——仿佛顾客专挑刚到货的商品买（买牛奶时人们确实如此，专掏保质期最晚的那瓶）。地球仪例中，LIFO 把最新那颗的 $16 费用化，哪怕顾客拿走的其实是 $15 的旧货。动机在通胀环境里格外清晰：最新的成本最高 → COGS 高 → 账面利润低 → 所得税负低。代价是期末存货滞留陈年低价，资产负债表失真。注意：国际财务报告准则（IFRS）禁止使用 LIFO，只有 US GAAP 允许——跨国比较报表时这是必须留意的口径差异。

5.2 配套例题：简例（7.10）

A 公司五台机器按采购先后为 A $10,250、B $12,700、C $14,000、D $14,350、E $17,650（合计 $68,950），每台售 $18,000，五月售出两台（实物上是 B 和 D，但 LIFO 不在乎）。从最底部向上取两台的成本：E $17,650 + D $14,350，COGS = $32,000；期末存货 = 68,950 − 32,000 = $36,950（= A+B+C = 10,250+12,700+14,000 ✓）；毛利润 = 36,000 − 32,000 = $4,000。同样的"卖两台机器"，LIFO 毛利 $4,000 vs FIFO 简例毛利 $10,600——成本上行期，LIFO 利润显著更低，这正是它的节税逻辑。分录：借现金 $36,000 / 贷销售收入 $36,000；借销售成本 $32,000 / 贷存货 $32,000。

5.3 配套例题：综合例（7.11，定期盘存）

沿用 4.3 的同一组数据（COGAS = 16,000 件 / $744,000，销量 9,000 件）。LIFO 从最新批次向前追溯：先吃 7/25 全部 8,000 件 × $50 = $400,000，还差 1,000 件从 7/13 批取 × $44 = $44,000——COGS = $444,000。期末存货 = 744,000 − 444,000 = $300,000；验证：7/1 批原封未动 2,000 × $40 = $80,000，加上 7/13 批剩余 5,000 × $44 = $220,000，合计 $300,000 ✓。对照 FIFO 综合例：COGS 高出 $50,000、期末存货低 $50,000——零和切分再次应验。

优点：通胀期把最接近现值的成本送进利润表，配比更及时，且税负最低（利润低），美国公司选用 LIFO 几乎都是冲着这条税务动机。缺点：期末存货可能沉淀几十年前的老成本，资产负债表严重失真；IFRS 禁用，跨国可比性差；利润被人为压低也会误导只看利润表的投资者。

六、加权平均法：不偏不倚的折中

6.1 规则

加权平均法（Weighted Average）放弃追踪批次，把全部可供销售成本摊平：

加权平均单位成本 = 可供销售商品总成本 ÷ 可供销售商品总数量

再用这个单价分别乘以销量（得 COGS）与剩余量（得期末存货）。它调和 FIFO 与 LIFO 的分歧，结果落在两者之间——但不是简单算术平均：大批量高成本批次会把均价往高处"拽"（所以叫加权）。注意按商品种类分别计算，不能把不同商品混在一起摊。适用场景与 FIFO/LIFO 相同：低价值、高销量、同质化商品（每袋乐事薯片都一模一样）。

6.2 配套例题：简例（7.12）

A 公司五台机器成本 A $12,600、B $13,500、C $12,750、D $14,400、E $15,700，合计 $68,950，每台售 $18,000，五月售出两台。第一步：平均单位成本 = 68,950 ÷ 5 = $13,790。第二步：COGS = 2 × 13,790 = $27,580；期末存货 = 3 × 13,790 = $41,370（= 68,950 − 27,580 ✓）；毛利润 = 36,000 − 27,580 = $8,420。分录：借现金 $36,000 / 贷销售收入 $36,000；借销售成本 $27,580 / 贷存货 $27,580。

6.3 配套例题：综合例（7.13，定期盘存）

同一组数据：COGAS = $744,000，可供 16,000 件，售出 9,000 件。平均单位成本 = 744,000 ÷ 16,000 = $46.50——合理性自检：46.50 落在最低批次 $40 与最高批次 $50 之间，且因 $50 批次量大（8,000 件）而更靠近 $50 ✓。COGS = 9,000 × 46.50 = $418,500；期末存货 = 744,000 − 418,500 = $325,500（= 7,000 × 46.50 ✓）。恰如预期：COGS 在 FIFO 的 $394,000 与 LIFO 的 $444,000 之间。

优点：平滑价格波动，不受单笔采购时点影响，计算最简单（定期制下一次除法搞定），数字永远居中、不易被指责操纵。缺点：两端信息都被抹平——期末存货不如 FIFO 贴近市价，COGS 不如 LIFO 贴近现值；"居中"在价格剧烈波动时意味着两头都不够准。

八、成本与可变现净值孰低：存货跌价必须认亏

计价方法决定存货按什么成本入账，但如果存货的市场价值跌破了成本怎么办？反直觉点在于：涨了就装没看见，跌了必须立刻认账——US GAAP 的稳健性要求：当存货价值（市价/重置成本）低于账面成本时，必须减记（Write-down）至较低者，规则称成本与市价孰低（Lower of Cost or Market, LCM）或成本与可变现净值孰低（Lower of Cost or Net Realizable Value, LCNRV）。例：$10 进货计划卖 $20，竞争对手杀价到 $8，你只能跟着卖 $8——市价 $8 < 成本 $10，每件确认 $2 损失；反之市价高于成本则不做任何处理（未实现利得不入账）。

九、比率分析：存货周转率与销售天数

存货躺在货架上 = 现金被冻结。衡量冻得快不快、解冻勤不勤的指标是存货周转率（Inventory Turnover）——一年内"进货→上架→售出→回款"这个循环能跑几圈：

存货周转率 = 销售成本（COGS）÷ 平均存货；平均存货 =（期初存货 + 期末存货）÷ 2

它是少数同时取数于利润表（COGS）与资产负债表（存货）的比率。但"一年 6.2 次"对管理者并不直观，于是换算成销售天数（Days to Sell）：

销售天数 = 365 ÷ 存货周转率

配套例题（7.15，百思买真实报表）：利润表 COGS = $329.18 亿；资产负债表期末存货 $54.09 亿、上年期末（=本年期初）$52.09 亿。平均存货 = (54.09 + 52.09) ÷ 2 = $53.09 亿；存货周转率 = 329.18 ÷ 53.09 ≈ 6.20 次；销售天数 = 365 ÷ 6.20 ≈ 58.87 天——从进货到卖出平均近两个月。好坏没有绝对标准：6.2 次单看很高，但若行业平均 30 天周转一次（约 12 次），百思买就是慢了一倍，得砍库存或促销提速。比率分析的价值正在于把规模悬殊的公司拉到同一标尺上——十亿美元的大零售商与几十万美元的小店可以直接比周转。优点：直观量化现金占用效率，横向纵向都可比；缺点：周转率还受计价方法影响（LIFO 压低期末存货会抬高周转率，跨公司比较前先看方法口径），且过快周转可能意味着缺货风险。
