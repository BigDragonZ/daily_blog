05 成本：短期、长期与沉没成本之外的决策

本篇覆盖 MIT 14.01《微观经济学原理》第 6 讲（L06）：从生产函数出发推导成本曲线（Cost Curve）——先看短期内固定成本与可变成本如何合成总成本，理解边际成本与平均成本的 U 形关系；再进入长期，用等成本线与等产量线的切点解决"工人与机器如何搭配"的成本最小化问题；最后把短期与长期成本曲线连成下包络线，解释特斯拉为什么要建 Gigafactory。（"沉没成本"是下一篇 L07 的主题，本篇聚焦成本曲线本身。）

一、引入：特斯拉的"产能地狱"

反直觉开场：同样是造一辆 Model 3，为什么在小工厂里加班加点赶出来，比建一座更大的工厂来造要贵得多？直觉上"厂小省钱、厂大烧钱"，现实却恰恰相反。

伊隆·马斯克最初预计到 2017 年汽车需求约 2 万辆，于是建了一座相对较小的工厂。结果实际需求飙升到 20 万辆。短期内工厂规模（资本）改不了，特斯拉只能让这座小厂超负荷运转——加班费、设备损耗、产线拥堵把每辆车的成本推得极高，马斯克称之为"产能地狱"（Production Hell）。只有在长期，他才能重新选择工厂规模：在内华达州建世界上最大的电池厂 Gigafactory，用大工厂在低得多的平均成本下生产。

这个故事里藏着本讲的全部主题：短期内资本固定、只能多雇工人，成本随产量加速上升；长期内所有投入都可调，企业能为目标产量选出最省钱的工厂规模。本讲的思想链路：核心问题（成本如何随产量变化）→ 简化模型（生产函数 Q = √(L·K) + 投入价格 W、R）→ 推导（短期成本函数 → MC/AC → 长期切点条件 → 长期成本函数）→ 实际应用（特斯拉建厂、最低工资辩论）→ 局限性（依赖生产函数形式、假设投入价格外生给定）。

二、从生产函数推导成本函数（Deriving the Cost Function）

沿用上一篇的生产函数 Q = √(L·K)：企业用劳动 L 与资本 K 两种投入生产 q 单位产品。劳动是可变投入（Variable Input），短期长期都能调整；资本是固定投入（Fixed Input），只能在长期改变。

企业生产的成本就是投入的数量乘以投入的价格：

  • 劳动成本：工时数 L × 每小时工资率（Wage Rate, W）；
  • 资本成本：机器数 K̄ × 租金率（Rental Rate, R）。注意是"租"不是"买"——正如你不会"买下"一个工人而是按小时付工资，我们也把机器看作按每个周期 R 的价格租用，这样资本和劳动都是"流量"，时间口径一致。可以把 R 理解为使用一台机器一个周期的全部成本。

于是短期总成本为 C = R·K̄ + W·L。给定 R = $10、W = $5，推导只需四步：

  1. 短期资本固定：Q = √(L·K̄)；
  2. 反解出劳动需求：L = Q² / K̄；
  3. 代入成本方程：C = 10·K̄ + 5·(Q² / K̄)；
  4. 取 K̄ = 1，得到短期成本函数：C = 10 + 5Q²。

其中 10 是固定成本（Fixed Cost, FC）——不随产量变化（租金照付）；5Q² 是可变成本（Variable Cost, VC）——随产量变化；两者之和是总成本（Total Cost, TC）。

图 1 解读：固定成本 FC = 10 是一条水平线（蓝），可变成本 VC = 5q² 从原点加速上升（绿），总成本 TC 是两者的垂直相加（红），即 VC 曲线整体向上平移 10 个单位。以 q = 2 为例：TC = 30 = FC 10 + VC 20。注意 TC 与 VC 都是凸向上的——产量翻倍，成本变成四倍，这正是短期资本固定、劳动边际产量递减的直接后果。

三、边际成本与平均成本（MC vs AC）

有了成本函数，就可以定义驱动整个企业分析的两个核心概念：

  • 边际成本（Marginal Cost, MC）：生产下一个单位的成本，MC = dC/dQ = 10Q——产量越大，边际成本越高；
  • 平均成本（Average Cost, AC）：整个生产范围内每个单位平均的成本，AC = C/Q = 10/Q + 5Q。

区分"边际"与"平均"至关重要：生产函数非线性时，两者通常不相等。平均成本 AC 可以拆成两部分：平均固定成本（Average Fixed Cost, AFC） = 10/Q 和平均可变成本（Average Variable Cost, AVC） = 5Q。

AC 为什么呈 U 形？刚开始生产时，寥寥几个单位要分摊全部固定成本，AFC 很高；随着产量增加，固定成本被摊到更多单位上，AFC 不断下降，把 AC 往下拉。但与此同时 AVC = 5Q 随产量持续上升。起初 AFC 摊薄的力量占主导，AC 下降；越过某个产量后，AVC 上升的力量反超，AC 掉头向上。两股力量的拉锯造就了 U 形。

图 2 解读：MC = 10q（蓝直线）与 AVC = 5q（绿线）都从原点出发，MC 斜率是 AVC 的两倍；AC = 10/q + 5q（红曲线）先降后升呈 U 形。关键几何事实：MC 恰好穿过 AC 的最低点 q* = √2 ≈ 1.41，此处 AC = MC = 10√2 ≈ 14.1。直觉是：只要"下一个单位的成本"低于平均值，它就会把平均值往下拉（MC < AC → AC 下降）；一旦高于平均值，就把它往上抬（MC > AC → AC 上升）——所以两者必然在 AC 的最低点相交。

这个模型的优缺点：优点是用一条 U 形曲线同时概括了"固定成本摊薄"与"边际产量递减"两股力量，并给出企业效率规模的明确预测（AC 最低点）；缺点是它完全由生产函数与投入价格推出——若规模报酬或技术形态不同，AC 未必是 U 形，且现实中 FC 与 VC 的划分常有时间口径上的模糊地带。

四、关键关系：MC = W / MPL

反直觉一问：企业为什么愿意为高技能员工支付高得多的工资？如果工资高意味着成本高，"压价雇便宜人"不是更省钱吗？未必。

短期内成本的变化只来自劳动的变化，即 dC = W·dL。于是：

MC = dC/dQ = W·(dL/dQ) = W / MPL

其中 劳动的边际产量（Marginal Product of Labor, MPL） = dQ/dL，即多雇一个工人能多生产多少。这个公式说：下一个单位的边际成本，随工资 W 上升而上升，随工人效率 MPL 上升而下降。用高效率工人生产下一个单位是便宜的——哪怕他工资更高，只要他多生产的产出足够多，摊到每单位上的成本反而更低。这就是企业愿意为高生产率付高工资的根本原因：比较的不是工资本身，而是每单位产出的成本 W/MPL。

五、长期成本最小化：等成本线与等产量线的切点

进入长期，资本 K 不再固定，企业可以自由选择"工人与机器的组合"。目标分两歩：先对给定产量找出成本最低的 (L, K)；再看这个最优组合如何随产量变化。

引入等成本线（Isocost Curve）：方程 C = W·L + R·K 在 K-L 空间中的图像，代表花费相同总成本的所有投入组合，是斜率为 −W/R 的直线。它与消费侧的预算约束线完全同构，区别只在于企业没有固定预算——我们画的是一族平行线，每条对应一个成本水平。

企业要生产给定产量（即待在某条等产量线（Isoquant）上）且成本最小，答案与消费者理论一模一样：等产量线与等成本线的切点。相切意味着两条线斜率相等：边际技术替代率（Marginal Rate of Technical Substitution, MRTS） = −MPL/MPK = −W/R。重排成"性价比"形式更直观：

MPL / W = MPK / R

即：花在劳动上的最后一美元带来的产量增量，必须等于花在资本上的最后一美元带来的产量增量。这与消费侧的 bang-for-the-buck 条件（MU₁/P₁ = MU₂/P₂）是完美的对偶——消费者分配预算让每美元的效用相等，生产者分配成本让每美元的产出相等。

图 3 解读：紫色曲线是产量 Q = 2 的等产量线（L·K = 4）。三条等成本线斜率都是 −W/R = −1/2：C = 20（灰虚线）太便宜，整条线够不到等产量线，根本生产不出 Q = 2；C = 40（橙虚线）与等产量线相交两次，能生产但浪费钱；C = 10·2√2 ≈ 28.3（蓝线）恰好与等产量线相切于 X 点（L = 2.83, K = 1.41）——这就是生产 Q = 2 的最低成本组合。切点处 MRTS = −K/L = −1/2 = −W/R，等价于 K = L/2：资本用量应是劳动的一半。

六、工资上涨：沿等产量线用资本替代劳动

投入品价格变化会怎样？假设工资 W 从 $5 涨到 $10，与租金率 R 持平，价格比从 −1/2 变为 −1。要保持产量不变（留在同一条等产量线上），企业会沿着等产量线移动：减少变贵的劳动、增加相对变便宜的资本——这就是企业层面的替代效应（Substitution Effect）。

图 4 解读：同一条等产量线 Q = 2（紫）上，工资上涨前最优组合是 X（L = 2.83, K = 1.41），等成本线（蓝）斜率 −1/2、成本 28.3；工资涨到 W = $10 后，等成本线（红）斜率变陡为 −1，最优组合移到 Y（L = 2, K = 2）——企业砍掉约 30% 的工人，换上更多机器。注意新成本 40 高于原成本 28.3：劳动变贵使任何产量都更贵了，企业能做的只是"少受伤"。

这个机制正是最低工资辩论的理论基础：一个常见论点认为，提高最低工资会抬高 W/R，诱使企业沿等产量线用机器（自助点餐机、仓储机器人）取代低技能工人，反而伤害政策想帮助的人群。该模型的优点是给出了"资本替代劳动"的清晰方向与可检验预测；缺点是把调整设想成无摩擦瞬时完成的——现实中裁员与购机都有调整成本，且需求、产出水平也可能同时变化（此处只刻画了保持产量不变的替代效应）。

七、长期扩张路径与长期成本函数

把每个产量水平下的最优投入组合连起来，得到的轨迹叫长期扩张路径（Long-run Expansion Path）。对本讲的 Cobb-Douglas 生产函数，它是一条直线 K = L/2——无论产量多大，最优资本-劳动比保持不变。但对其他生产函数，扩张路径可以弯曲：偏向资本（重型机械行业）或偏向劳动（快餐店）。

图 5 解读：蓝直线是扩张路径 K = L/2，三条紫色虚线分别是 Q = 1、2、3 的等产量线。切点 E₁（1.41, 0.71）、E₂（2.83, 1.41）、E₃（4.24, 2.12）都落在射线上：产量每上一个台阶，劳动与资本都按同一比例同步扩张。

把最优组合代回成本方程，就得到本讲的目标——长期成本函数：由 K = L/2 得 Q = L/√2，即 L = √2·Q、K = (√2/2)·Q，代入 C = W·L + R·K：

C = 5·(√2·Q) + 10·(√2/2·Q) = 10√2·Q ≈ 14.1·Q

长期成本与产量成正比——这是该生产函数规模报酬不变（Constant Returns to Scale, CRS）的直接结果。对比短期成本 C = 10 + 5Q² 的加速上升，长期成本之所以更低，是因为企业能同步扩大资本，避免"在小厂里硬塞更多工人"导致的边际产量递减。

八、短期与长期的关系：LRAC 是 SRAC 的下包络线

长期成本总是低于或等于短期成本——原因很简单：长期拥有更多自由度。短期你被锁死在某个工厂规模（K̄ 固定）上；长期你能为预期产量选出最优的工厂规模。

假设企业可以建三种规模的工厂：小型（K̄ = 1）、中型（K̄ = 2）、大型（K̄ = 4），各自对应一条短期平均成本（Short-run Average Cost, SRAC）曲线 SRAC = 10K̄/q + 5q/K̄。计划产量低时小厂最省，计划产量高时大厂最省。长期平均成本（Long-run Average Cost, LRAC）就是所有可能 SRAC 曲线的下包络线（Lower Envelope）。

图 6 解读：三条 U 形曲线分别是小厂 SRAC₁（蓝，最低点 q* = 1.41）、中厂 SRAC₂（红，q* = 2.83）、大厂 SRAC₃（绿，q* = 5.66），最低平均成本都是 10√2 ≈ 14.1（星标）。若计划产量 q < 2 选小厂最省，2 < q < 4 选中厂，q > 4 选大厂。灰色虚线是真正的 LRAC：本例因规模报酬不变，它是一条水平线 10√2 ≈ 14.1，与每条 SRAC 在其最低点相切。一般情形下（工厂规模连续可选、规模报酬先增后减），LRAC 是一条平滑的浅 U 形曲线，贴着无数条 SRAC 的下缘滑过——所以它才叫"包络线"。

回到特斯拉：马斯克按 2 万辆需求建的小厂相当于 SRAC₁。需求冲到 20 万辆后，短期只能沿 SRAC₁ 向右上方硬撑——平均成本飙升，这就是产能地狱的成本语言。内华达 Gigafactory 则相当于从 SRAC₁ 跳到 SRAC₃：在更高产量上把平均成本压回包络线附近。短期受约束、长期重新优化，一张图说尽。

九、总结：短期 vs 长期成本决策

维度短期（Short Run）长期（Long Run）
可调整的投入只有劳动 L（资本 K̄ 固定）劳动与资本均可调
成本结构固定成本 FC + 可变成本 VC全部成本都是可变的（无 FC）
本讲成本函数C = 10 + 5Q²（凸向上，加速上升）C = 10√2·Q ≈ 14.1·Q（线性，比例上升）
核心曲线MC = 10Q；AC = 10/Q + 5Q（U 形）LRAC = SRAC 的下包络线
决策规则关注 MC = W/MPL 与 AC 最低点切点条件 MPL/W = MPK/R，沿扩张路径扩张
价格变化的应对只能增减工人沿等产量线替代（工资涨→资本替代劳动）
成本大小关系SRAC ≥ LRAC（被工厂规模锁死）LRAC ≤ SRAC（自由选最优规模）
特斯拉案例小厂超负荷赶工 = 产能地狱Gigafactory = 跳到更大规模的 SRAC

本篇思想链路：核心问题（成本如何随产量变化、投入如何搭配）→ 简化模型（Q = √(L·K)，W = $5，R = $10）→ 推导（短期 C = 10 + 5Q² → MC/AC 与 MC = W/MPL → 长期切点 MPL/W = MPK/R → 扩张路径 → C = 10√2·Q → LRAC 包络线）→ 实际应用（特斯拉 Gigafactory、最低工资辩论、高薪雇高生产率工人）→ 局限性（结论依赖 Cobb-Douglas 形式、忽略调整成本与投入价格内生性、CRS 下 LRAC 水平的结论不具普遍性）。
