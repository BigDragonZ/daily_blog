06 完全竞争：利润最大化、停产与长期均衡

本篇覆盖 MIT 14.01《微观经济学原理》第 7、8 两讲（L07+L08）：从一个"亏本卖票反而赚了"的反直觉故事出发，分清沉没成本与固定成本；进入完全竞争（Perfect Competition）市场，看价格接受者如何用 P = MC 决定产量；再回答两个更难的问题——亏到什么程度才该停产？为什么长期竞争会把利润压到零？

一、L07 竞争 I（Competition I）：沉没成本、价格接受者与 P = MC

1.1 引入：240 美元买的门票只能卖 220 —— 你亏了吗？

反直觉开场：教授花 240 美元买了两张 Journey 乐队演唱会门票，临近演出发现自己其实没那么喜欢这支乐队，于是在二手平台以 220 美元卖出。直觉上他"亏了 20 美元"。但正确答案是：这个问题本身就问错了——那 240 美元在卖票那一刻已经与他无关了。

1.2 沉没成本 vs 固定成本

沉没成本（Sunk Cost）是指无论你从现在起采取任何行动，都无法改变的成本——一旦投入就永远无法撤销的投资。它与固定成本（Fixed Cost, FC）不同：

  • 以一名医生为例：短期内，可变成本是工作时长、雇佣护士的数量；
  • 长期内，办公室大小这个固定成本可以调整（换大或换小）；
  • 但上医学院的投入是沉没成本——你永远无法"撤销"上过医学院这件事，那笔费用一去不复返。

可以把沉没成本理解为"长期的固定成本"：固定成本在长期尚可调整，沉没成本连长期也无法收回。

1.3 沉没成本谬误（Sunk Cost Fallacy）

回到门票故事。教授最初想"我至少得把 240 美元赚回来"，随后意识到这完全错了——240 美元已经花出去、已经沉没，与卖票决策无关。正确的思考方式只问一个问题：我现在还愿意花多少钱去看这场演唱会？

  • 假设他现在只愿意付 100 美元去看。那么：票价能卖到 100 美元以上就卖，卖不到就自己去；
  • 最终以 220 美元卖出 → 他做的是一个好决策（用只值 100 美元的东西换回 220 美元），而不是"亏了 20 美元"。

经济学家把"关注了已经无关紧要的事情"称为沉没成本谬误（Sunk Cost Fallacy）。另一个典型例子是房地产市场：许多房主坚持"不想以低于买入价出售"。但你当初付了多少钱并不重要，重要的是现在能卖多少钱，以及你是否愿意以那个价格出售（有抵押贷款现金流约束时情况复杂些，但原理相同）。

1.4 完全竞争三条件与价格接受者

生产者理论中我们有一系列等产量线与等成本线的切点，却不知道该选哪个产量——这个缺失的约束来自市场。三种市场结构中（完全竞争 / 垄断（Monopoly） / 寡头垄断（Oligopoly）），本节从最极端的完全竞争（Perfect Competition）开始。

完全竞争市场的技术性定义：生产者是价格接受者（Price Taker）——单个生产者对售价没有任何影响力，市场价格对它是给定的。这发生在公司面临的需求完全有弹性（Perfectly Elastic）时：无论卖多少，价格总是 P，变化的只有数量。成为完全竞争市场需要三个条件：

  1. 产品同质化（Identical Products）：所有公司销售的商品在消费者看来完全相同；
  2. 信息完全（Full Information）：消费者了解每个公司收取的价格；
  3. 交易成本低（Low Transaction Costs）：消费者可以毫不费力地比较和选择卖家。

现实中几乎没有市场完全满足这三条，但 eBay 很接近：搜索"72 英寸红色椭圆形鞋带"，产品基本相同、价格一目了然、比较毫不费力。另一个例子是埃菲尔铁塔下卖纪念品的小贩。

1.5 公司需求 vs 市场需求：剩余需求与弹性公式

反直觉之处：市场需求曲线明明向下倾斜（弹性并不大），单个公司面临的需求却可以近乎水平。关键在于区分两条曲线：

  • 市场需求（Market Demand，大写 Q）：第一课就讲的向下倾斜的需求曲线；
  • 公司需求（Firm Demand，小写 q）：剩余需求（Residual Demand），即市场总需求减去其他所有公司的供给：q(P) = Q(P) − S_other(P)。

单个公司的需求弹性（Elasticity of Demand, ε）可以用下式推导：

ε_i = n · ε − (n − 1) · η

其中 n 是公司数量，ε 是市场需求弹性，η 是市场供给弹性（Elasticity of Supply, η）。代入 n = 100、ε = −1、η = 1：

ε_i = 100 × (−1) − 99 × 1 = −199

−199 已接近负无穷——单个公司面对的是一条近乎水平的需求曲线。所以"市场不弹性 ≠ 公司不弹性"：在埃菲尔铁塔下卖纪念品，你提价一欧元就没人买你的，降价一欧元所有人都来你这儿买。"完全弹性需求"的假设并不疯狂。

1.6 经济利润 vs 会计利润

会计师说利润 = 收入 − 成本；经济学家认为这漏掉了机会成本（Opportunity Cost）。讲义案例：你毕业后开了一家网站设计公司，雇一名程序员（年薪 4 万美元），用自己的一台闲置电脑，第一年销售额 6 万美元：

  • 会计利润（Accounting Profit） = 60,000 − 40,000 = +20,000 美元；
  • 经济利润（Economic Profit） 要计入机会成本：你的时间（不创业去工作本可赚 80,000）+ 你的电脑（可卖 1,000）。真实成本 = 40,000 + 80,000 + 1,000 = 121,000；
  • 经济利润 = 60,000 − 121,000 = −61,000 美元。

账面上赚 2 万，经济上亏 6.1 万——后文的"利润"一律指经济利润。这也为 L08 的"长期零利润"埋下伏笔：零经济利润不等于白干，而是说所有资源（包括你自己的时间和设备）都已拿到市场水平的回报。

1.7 利润最大化法则：P = MC

利润 π = R − C（收入 − 成本）。对产量 q 求导并令其为零：dπ/dq = dR/dq − dC/dq = 0，即 边际收入（Marginal Revenue, MR） = 边际成本（Marginal Cost, MC）。完全竞争公司是价格接受者，每多卖一单位的额外收入就是市场价格 P，即 MR = P。于是利润最大化条件为：

P = MC　—— 持续生产，直到"再生产一单位的成本"恰好等于"它能卖的价格"

数值例（沿用上一篇的成本函数）：C(q) = 10 + 5q²，市场价格 P = 30：

  • MC = dC/dq = 10q；令 P = MC：30 = 10q → 最优产量 q* = 3；
  • 收入 R = 30 × 3 = 90；成本 C = 10 + 5 × 3² = 55；利润 π = 35；
  • 验证：若生产第 4 个单位，MC(4) = 40 > 30，卖 30 美元却花 40 美元造，亏 10 美元——所以停在 q = 3。

图形上，单位利润 = 价格 − 平均成本（Average Cost, AC）。在 q* = 3 处 AC = 55/3 ≈ 18.33，单位利润 = 30 − 18.33 = 11.67，总利润 = 11.67 × 3 = 35，即下图中绿色利润矩形（高 11.67 × 宽 3）。

图 1 解读：蓝线是 MC = 10q，紫色曲线是 AC = 10/q + 5q，红色水平线是市场价格 P = 30（公司面对的需求=价格线）。MC 与价格线交于 (3, 30)——利润最大化产量 q* = 3；该产量下 AC = 18.33，绿色矩形（高 = 30 − 18.33 = 11.67，宽 = 3）就是总利润 35。点 (4, 40) 说明为何不生产第 4 个单位：其边际成本 40 已高于售价 30。

P = MC 模型的优缺点：优点是把"生产多少"这个看似模糊的决策压缩成一条可操作的规则，且只需要成本函数和市场价格两个可观测输入；缺点是一阶条件只保证极值不保证最大（需 MC 递增穿过价格线），且它回答的是"生产多少"，还没回答"要不要生产"——后者是 L08 的停产规则。

1.8 从量税 vs 固定税

如果政府对每单位产品征收 10 美元的从量税（Per-unit Tax）：

  • 新成本函数 C_new = (10 + 5q²) + 10q，新边际成本 MC_new = 10q + 10；
  • 利润最大化：30 = 10q + 10 → 最优产量降到 q* = 2；
  • 新平均成本 AC′(2) = 10/2 + 5×2 + 10 = 25，单位利润 = 30 − 25 = 5，总利润 = 5 × 2 = 10。

从量税抬高 MC，公司减产；同时 AC 也上移，单位利润缩水——利润矩形又高又宽地双向缩小（35 → 10）。

相比之下，若政府征收 10 美元的固定税（Fixed / Lump-sum Tax）（与产量无关）：成本函数变为 C_new = (10 + 10) + 5q²，MC 不变，产量决策不变（q* 仍为 3），只是 AC 上移到 (20 + 45)/3 ≈ 21.67，总利润从 35 降到 25。固定税只削利润、不改产量。

图 2 解读：蓝色 MC = 10q 与价格线 P = 30 交于 (3, 30)，税前 q* = 3，绿色利润矩形 π = 35；从量税使 MC 上移为红色 MC′ = 10q + 10，与价格线交于 (2, 30)，税后 q* = 2，且 AC 也上移到红色虚线 AC′（q=2 处 AC′ = 25），利润矩形缩为橙色的 π = 10。矩形的高（11.67→5）和宽（3→2）同时缩水。

税种边际成本 MC平均成本 AC最优产量 q*总利润 π
无税（基准）10q10/q + 5q335

二、L08 竞争 II（Competition II）：停产、供给曲线与长期均衡

2.1 引入：价格在亏本线以下，老板还在开工 —— 理性还是执拗？

反直觉开场：市场价格跌到 10 美元，而这家公司造一个单位要花 15 美元——明摆着亏本，老板却继续开工。是理性还是执拗？答案藏在"反正都要付的钱"里：停不停产，固定成本都照付，所以正确的比较不是"赚还是亏"，而是"哪个亏得更少"。

2.2 停产规则：仅当 P < AVC 才停产

短期内没有进入和退出，公司不能真正离开市场，但可以选择产量为零——这叫停产（Shut Down），与退出（Exit）（卷铺盖走人）不同：停产时你已支付了固定成本，无处可去。设价格从 30 突然降到 10，回到原成本函数 C = 10 + 5q²：

  • 继续生产：P = MC → 10 = 10q → q = 1。收入 R = 10，成本 C = 10 + 5 = 15，利润 π = −5；
  • 停产（q = 0）：收入为零，但固定成本照付 10，利润 π = −10。

生产亏 5、停产亏 10——即使亏本也应该继续生产那一个单位。推广成规则：只有当你的收入低于可变成本（Variable Cost, VC）时才停产，因为固定成本无论如何都得付（它已经是沉没的）。两边同除以 q，停产规则写为：

仅当 P < AVC（Average Variable Cost，平均可变成本） 时才停产

对本例，可变成本 = 5q²，AVC = 5q；最优点 P = MC = 10q → q = P/10，代入得 AVC = 5 × (P/10) = 0.5P。停产条件 P < 0.5P 对任何正价格都不可能成立——对这个成本函数，公司永远不会停产。

2.3 供给曲线 = MC 曲线在 AVC 以上的部分

现在把每个价格下的最优产量描出来：P = 10 → q = 1；P = 20 → q = 2；P = 30 → q = 3；P = 40 → q = 4。这条从 (0,0) 到 (4,40) 的线就是 MC 线——在每个点上价格都等于边际成本。经过这么多数学推导，这条 MC 线是什么？它就是供给曲线（Supply Curve）——"市场价格与生产者愿意生产的数量之间的关系"，正是边际成本曲线所描述的。严格地说，公司供给曲线是 MC 曲线在 AVC 最低点以上的部分（AVC 以下公司宁可停产，供给为零）。至此我们从第一性原理（生产函数 + 投入品价格 + 完全竞争）推导出了第一讲直接使用的供给曲线，完成了闭环。

图 3 解读：蓝色 MC = 10q 即公司供给曲线，四个圆点对应价格 10/20/30/40 → 产量 1/2/3/4；灰色虚线是 AVC = 5q，始终位于 MC 下方，故本例整条 MC 都是供给曲线。红色小矩形展示 P = 10 时的亏损：q = 1 处 AC = 15，单位亏 5、共亏 5——但这仍好于停产的亏 10（且 AVC(1) = 5 < P = 10，停产规则说继续生产）。

2.4 短期均衡五步法

有了单个公司的供给曲线，把它水平加总就得到市场供给曲线（Market Supply Curve）：每增加一个相同的公司，同一价格下总供给量翻倍，市场供给曲线变得更平坦、更有弹性。推导短期均衡（Short-run Equilibrium）的五步：

  1. 确定成本函数：短期资本 K̄ 固定，由生产函数和投入品价格（工资 w、租金 r）推出 C = 10 + 5q²；
  2. 推导公司供给曲线：P = MC，MC = 10q → 公司供给 q = P/10；
  3. 推导市场供给曲线：水平加总。设短期市场上有 n = 6 家公司，Q = 6 × (P/10) = (3/5)P；
  4. 与需求联立：设市场需求 Q = 48 − P。令供给 = 需求：(3/5)P = 48 − P，解得均衡价格 P* = 30；
  5. 计算均衡数量：Q* = 48 − 30 = 18；每家公司生产 q = 30/10 = 3，6 家 × 3 = 18，供需平衡。

图 4 解读：蓝色市场供给 Q = (3/5)P（6 家相同公司水平加总，比单个公司更平坦）与红色市场需求 Q = 48 − P 交于均衡点 (Q* = 18, P* = 30)。这个价格正是 1.7 节里单个公司"当作给定"的 P = 30——市场决定了价格，公司在该价格下各自生产 q = 3。

2.5 长期均衡：进入与退出把利润压到零

五步法的 n = 6 从哪来？答案在长期竞争（Long-run Competition）里：长期允许公司进入（Entry）与退出（Exit），且所有成本都是可变的（没有停产规则那种复杂情形——长期亏损就退出）。基本法则：

  • 有利润 → 公司进入 → 市场供给增加、价格下降、利润被挤压；
  • 有亏损 → 公司退出 → 市场供给减少、价格上升、亏损被消除；
  • 两股力量的终点：长期竞争均衡中经济利润为零，公司在 AC 最低点生产，长期市场供给曲线完全弹性（水平），价格 = 行业最低平均成本。

（沿用本例成本函数可算出这个长期价格：AC = 10/q + 5q 在 q = √2 ≈ 1.41 处取最小值 ≈ 14.14——若允许自由进出，价格最终会被压到 14.14 附近。）

图 5 / 图 6 解读：左图（PC 市场，进入）：1990 年代初 PC 需求旺盛而厂商少，供给 SR₁ 与需求 D 交于较高价格 P₁ = 20，戴尔赚到厚利；Gateway 等公司看到利润进入，供给右移变平到 SR₂，价格降至 P₂ = 15，戴尔的利润矩形缩小——只要还有利润进入就会继续，直到利润归零。右图（大型机市场，退出）：PC 兴起使大型机需求下降到 D′，价格 P₁ = 20 低于 IBM 的平均成本、IBM 亏损；一些公司退出，供给左移变陡到 SR₂，价格回升到 P₂ = 22.5 = 最低 AC，利润归零，市场达到长期均衡。两个案例方向相反、机制相同：进入和退出分别消灭正利润和负利润。

2.6 零利润的三个现实修正

现实中公司明明在赚钱、股市也很繁荣，"零利润"听起来不现实——因为模型建立在极端假设上。三个修正：

  1. 进入壁垒（Barriers to Entry）：模型假设公司可以无成本自由进出，但现实中存在巨大沉没成本（建厂、研发）、政府许可、品牌忠诚度等壁垒。只要利润不高于跨越壁垒的成本，新公司就不会进入，现有公司可保住长期利润；
  2. 公司差异（Firms Differ）：模型假设所有公司相同，但现实中成本结构不同。以棉花市场为例：巴基斯坦棉农的生产成本比美国低，若全球需求大到价格必须高到让美国农民也愿意种棉花，巴基斯坦的低成本棉农就能以这个高市场价出售，获得长期利润；
  3. 投入品价格变化（Input Prices Change）：模型假设工资、原材料价格固定，但行业扩张会推高对劳动力和原材料的需求、抬高投入品价格，使所有公司的成本曲线上移。为吸引更多产量，市场价格必须上涨——长期供给曲线向上倾斜而非水平，即使每个公司的利润最终仍为零。

模型的关键启示是方向性的：竞争持续推动公司走向成本最小化和零利润。现实修正只是让均衡偏离终点，并没有取消这股压力。

完全竞争长期模型的优缺点：优点是只用"自由进出"一条假设就预言了价格水平（= 最低 AC）、生产效率（AC 最低点）和利润趋势（→ 0），解释力极强；缺点是三个核心假设（自由进出、公司同质、投入品价格不变）在现实中都不严格成立，所以它更适合作为衡量现实市场的基准（benchmark）而非精确描述。
