10 短期经济

本篇覆盖短期宏观经济波动的两章：总需求-总供给模型（AD/AS）——分析经济为什么会波动；以及货币政策与财政政策如何通过这个模型影响总需求。

总需求与总供给（Aggregate Demand and Aggregate Supply）

核心：整个经济体的总需求与总供给

总需求-总供给模型（AD/AS Model）在图形机制上很像微观经济学的供求模型，但本质截然不同：微观模型分析单一商品，而这里考虑的是整个经济体中所有商品和服务的总需求与总供给。模型的功能：帮助我们理解经济波动的成因——什么导致衰退（Recession）、什么导致扩张（Expansion），以及如何帮助经济走出衰退。

关于经济波动的三个关键事实

  1. 经济波动是无规律且不可预测的。声称能预测下一次衰退的人通常是在推销书籍或投资产品。"商业周期"（Business Cycle）这个词其实有误导性——它暗示正弦波般的规律，但经济波动并非如此。
  2. 大多数宏观经济变量同时波动。衰退时收入下降、企业利润减少、失业率上升、房屋止赎率上升……它们趋向一同变动，但关系复杂，并非简单同步。
  3. 产出下降，失业率上升。这是最关键、最稳固的关系：用实际 GDP 衡量产出与收入，产出下降时失业率随之上升。

短期与长期的对比

之前的模型（可贷资金市场、货币中性）都是长期模型：变量分为名义与实际两类，货币供给的变化只影响名义变量。但 AD/AS 是一个短期模型，专注解释经济的短期波动。它的核心是分析物价水平（Price Level, P）（名义变量）与实际 GDP（Y）（实际变量）之间的关系——长期中两者无关，短期内却确实存在关联，这正是本模型的关键。

模型的图线与详细解释

模型的坐标（图 1）：纵轴是物价水平 P（所有商品和服务的平均价格），横轴是实际 GDP Y（经济的总产出 = 总收入，Y = C + I + G + NX）。三条曲线：

  • 总需求曲线（Aggregate Demand, AD）：向下倾斜——每个物价水平下，家庭、企业、政府和外国客户想购买的总量。物价越高，总需求量越低。
  • 短期总供给曲线（Short-Run Aggregate Supply, SRAS）：向上倾斜——每个物价水平下，所有企业选择生产和销售的总量。
  • 长期总供给曲线（Long-Run Aggregate Supply, LRAS）：垂直——长期中产出取决于真实生产能力，与物价水平无关。

长期均衡在 AD 与 LRAS 的交点（图 1 中 A 点），SRAS 也穿过该点（预期物价 = 实际物价）。对应均衡物价水平 P* 与自然产出率 YN。

总需求曲线为什么向下倾斜

原因与微观需求曲线完全不同（不是收入效应和替代效应——整个经济没有可"替代"的对象）：

  1. 财富效应（Wealth Effect）：物价下降 → 货币的实际价值增加，消费者感觉更富有 → 消费 C 增加 → 总需求量增加。
  2. 利率效应（Interest-Rate Effect）：物价下降 → 交易所需货币减少 → 多余货币存入银行或买债券 → 可贷资金供给增加 → 利率下降 → 企业投资 I 增加 → 总需求量增加。
  3. 净出口效应（Net Export Effect）：物价下降 → 利率下降 → 本国资产对外国投资者吸引力减小 → 资本外流、本币贬值 → 本国商品相对便宜 → 出口增、进口减 → 净出口 NX 增加。

总需求曲线的移动

任何在给定物价水平下改变 C、I、G、NX 的事件都会移动 AD：

  • 消费 C：悲观情绪（战争、疫情、股市崩盘）→ 减少支出增加储蓄 → AD 左移；减税增加可支配收入 → AD 右移。
  • 投资 I：企业对未来乐观（如新技术出现）→ AD 右移；投资税收抵免 → AD 右移；货币供给增加使利率下降 → AD 右移（下一章详述）。
  • 政府购买 G：最直接的政策工具——增加基础设施、国防支出直接使 AD 右移。
  • 净出口 NX：欧洲发生衰退 → 减少购买美国商品 → AD 左移；资本流动引起的汇率变动也会影响 NX。

总供给曲线：长期垂直，短期上倾

长期总供给（LRAS）：长期中供给量取决于真实生产能力——劳动力、资本、自然资源、技术知识——与物价水平无关，因此垂直。垂线所在位置称自然产出率（Natural Rate of Output）（或充分就业产出）。移动因素：劳动力（移民增加右移；最低工资大幅提高致结构性失业增加则左移）、资本（物质与人力资本增加右移）、自然资源（新矿藏发现右移）、技术知识（进步右移——增长最重要的驱动力）。

短期总供给（SRAS）：短期内物价水平确实影响产出，曲线向上倾斜。三种解释理论：

  1. 粘性工资理论（Sticky Wage Theory）：名义工资因长期合同或社会规范调整缓慢。物价意外下降而工资不变 → 实际工资上升 → 成本增加 → 企业减雇减产。
  2. 粘性价格理论（Sticky Price Theory）：菜单成本使部分价格调整缓慢。物价意外下降时，价格粘性的企业产品相对变贵 → 销量下降 → 削减产量。
  3. 错觉理论（Misperceptions Theory）：物价总水平下降时，企业误以为是自己产品的相对价格下降 → 认为生产收益减少 → 减少产量。

三个理论指向同一结论：

产出供给量 = 自然产出率 + a ×（实际物价水平 − 预期物价水平）
a 是决定产出对未预期物价变动反应程度的系数。当实际物价偏离预期时，短期产出就偏离自然产出率。

SRAS 的移动：所有移动 LRAS 的因素（劳动、资本、资源、技术）同样移动 SRAS；此外还有独特因素——预期物价水平：企业预期未来物价上升 → 预期成本（工资）上升 → 现在就要求更高价格 → 每个物价水平下供给减少 → SRAS 左移；预期物价下降则右移。

需求和供给变化的影响：两个案例

案例一：总需求下降（经济衰退）。经济原在长期均衡 A。股市崩盘或悲观情绪蔓延使 AD1 左移至 AD2（图 2）：

  1. 短期：移到 B 点（AD2 与 SRAS1 交点）——产出降至 Y2（低于自然产出率）、物价降至 P2，经济陷入衰退，失业率上升。
  2. 长期调整：政策干预（扩张性政策把 AD 移回 AD1，快速回到 A）；或自然调整——低物价逐渐降低人们的预期，SRAS 右移（SRAS1→SRAS2），直到 C 点：产出回到 YN，物价进一步降至 P3。

历史案例：1930 年代大萧条可视为巨大的总需求下降——实际 GDP 下降约 27%，失业率飙升至 25%，物价水平下降 22%；二战期间政府支出大增则是巨大的总需求扩张，把美国经济带出了大萧条。

案例二：总供给下降（滞胀）。关键原材料（如石油）价格突然飙升 → 生产成本大增 → SRAS1 左移至 SRAS2（图 3）：

  1. 短期：移到 B 点——产出降至 Y2，但物价上升至 P2。产出停滞（Stagnation）与通货膨胀（Inflation）并存，即滞胀（Stagflation），尤为痛苦。
  2. 长期：政策制定者面临两难——扩张总需求对抗衰退会进一步推高物价；紧缩对抗通胀会让衰退更严重。若不干预且冲击是暂时的，高失业最终压低工资物价，SRAS 移回原位，经济回到 A。

历史案例：2020 年 COVID-19 是罕见的双重冲击——封锁与恐惧使消费投资锐减（AD 左移），停工与供应链中断使供给减少（SRAS 左移），产出急剧下降。

政策影响（货币与财政政策）

两个重点政策

  • 货币政策（Monetary Policy）：主要涉及货币供给量的变动以及银行体系的运作方式，核心是改变经济中的货币数量。货币供给由美联储控制而非政治家——制度设计有意将美联储与政治过程隔离以保证独立性。
  • 财政政策（Fiscal Policy）：与政府的支出和税收决策有关，即之前课程讨论过的政府购买 G 和税收 T。

两种政策都能移动总需求曲线。本章重点关注利率效应对总需求的影响。

流动性偏好理论

为深入理解利率效应，引入凯恩斯的流动性偏好理论（Theory of Liquidity Preference）——解释短期利率决定的模型（与解释长期利率的可贷资金模型对应）。流动性指资产转换为交易媒介的难易程度，该理论研究人们对流动性最强的资产——货币——的需求。

  • 货币供给：假设完全由美联储通过公开市场操作等工具设定，与利率无关 → 以利率为纵轴、货币量为横轴的图中，货币供给曲线是垂线。
  • 货币需求：人们持有货币主要为交易，但持有货币有机会成本——不持有货币而持有债券等有息资产本可获得的利息。利率就是持有货币的机会成本：利率高 → 机会成本高 → 人们转向债券、货币需求少；利率低 → 持有货币损失小、需求多。因此货币需求曲线向下倾斜。
  • 货币市场均衡（图 4）：供给与需求的交点决定均衡利率（Equilibrium Interest Rate）。利率低于均衡时货币需求超过供给，人们出售债券换货币 → 债券价格下跌、利率上升；反之亦然——市场力量自动把利率推向均衡。

用此模型可以清晰展示利率效应链条：

  1. 物价水平上升 → 交易需要更多货币 → 货币需求曲线右移；
  2. 货币供给不变 → 均衡利率上升；
  3. 更高利率提高借贷成本 → 抑制企业投资与居民消费（购房、购车）→ 总需求量减少。

这正是总需求曲线向下倾斜的关键机制。

货币政策如何影响总需求

以经济面临衰退风险时的扩张性货币政策为例（图 5、图 6）：

  1. 美联储通过公开市场操作购买政府债券，向银行体系注入准备金 → 货币供给增加；
  2. 货币供给曲线右移（MS1→MS2，图 5）；
  3. 货币需求不变 → 均衡利率下降（r1→r2）；
  4. 利率下降降低借贷成本 → 刺激企业投资与居民消费；
  5. 任何给定物价水平下的总需求量增加 → 总需求曲线右移（AD1→AD2，图 6），短期均衡从 A 到 B：产出 Y 上升、物价 P 上升。

反之，面临通胀压力时美联储可减少货币供给 → 利率上升 → AD 左移。美联储可以通过设定货币供给目标或利率目标（如联邦基金利率）来调控总需求。

财政政策如何影响总需求

  • 政府购买 G：直接影响。政府增加 100 亿美元修建高速公路，这 100 亿直接计入总需求 → AD 右移。
  • 税收 T：间接影响。减税增加家庭可支配收入 → 刺激消费；投资税收抵免激励企业投资 → C 和 I 增加 → AD 右移。

乘数效应与挤出效应

财政政策的最终影响比初始变动量复杂，涉及两种方向相反的效应：

  • 乘数效应（Multiplier Effect）：初始支出会被放大。政府支出 100 亿成为承包商和工人的收入，他们按边际消费倾向（Marginal Propensity to Consume, MPC）把一部分花掉，又成为别人的收入，循环往复。乘数公式：Multiplier = 1 ÷ (1 − MPC)。MPC = 0.75 时乘数为 4——100 亿支出最终可能使总需求增加 400 亿。
  • 挤出效应（Crowding-Out Effect）：政府增加支出（往往靠借贷融资）→ 资金需求增加 → 利率上升 → 抑制私人投资——政府支出"挤出"私人投资，部分抵消财政扩张的效果。

一项财政政策对总需求的最终影响，取决于乘数效应与挤出效应的相对大小。

关于稳定经济政策的争论

  • 支持积极干预者：经济偏离自然产出水平时，政府和中央银行应主动调整总需求，减轻衰退的严重程度。
  • 反对积极干预者：政策存在漫长且不确定的时滞（认识时滞、决策时滞、实施时滞），干预往往为时已晚，甚至可能加剧波动，弊大于利。

此外，经济中存在自动稳定器（Automatic Stabilizers）——如累进税制度和失业保险：衰退时自动减税增支（税收减少、转移支付增加）刺激总需求，过热时自动抑制，无需政府采取额外行动。
