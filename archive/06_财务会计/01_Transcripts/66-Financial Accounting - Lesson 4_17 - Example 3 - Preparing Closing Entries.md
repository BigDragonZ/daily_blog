### 结账分录概述

本节最后一个案例是关于编制**结账分录 (Closing Entries)**。回顾一下会计期末的流程：首先进行调整，完成调整后，我们编制**调整后试算表 (Adjusted Trial Balance)**，然后根据它来编制**财务报表 (Financial Statements)**。

本节我们没有实际编制财务报表，因为其编制方法与之前章节所述完全相同，所以在此不再赘述。我们今天要展示的是在此之后的一个新步骤，即结账流程。当我们为外部使用者编制完财务报表后，就需要结清账簿，为下一个会计期间做准备。这个过程需要通过编制**日记账分录 (Journal Entries)** 来完成。

本案例将专门向您展示结账分录的具体操作。

### 案例数据：调整后试算表

这是上一个案例中的调整后试算表，现在我们需要利用这份报表为 A 公司编制结账分录。

为了清晰起见，我只截取了编制结账分录所需的部分。我们只需要结清**收入 (Revenues)**、**费用 (Expenses)** 和**股利 (Dividends)** 这些**临时账户 (Temporary Accounts)**。此处的试算表只包含了收入和费用项目（本案例无股利），因此借贷方总额不相等，因为它是一个不完整的试算表。

### 步骤一：结清收入账户

结账的第一步是结清所有收入账户。在此案例中，我们有两个收入账户：**服务收入 (Service Revenue)** 和**销售收入 (Sales Revenue)**。

目前，这两个账户都显示为贷方余额。为了将它们结清归零，我们需要做相反的操作，也就是借记这两个账户。同时，将总金额贷记到**留存收益 (Retained Earnings)** 账户中。

- **服务收入 (Service Revenue)** 的贷方余额为 14,120 美元。
- **销售收入 (Sales Revenue)** 的贷方余额为 33,950 美元。

分录如下：

| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 服务收入 (Service Revenue) | 14,120 | |
| 销售收入 (Sales Revenue) | 33,950 | |
| 留存收益 (Retained Earnings) | | 48,070 |

完成此步骤后，所有收入账户的余额都变为零，为下一个年度做好了准备。

### 步骤二：结清费用账户

第二步是结清所有费用账户。费用的正常余额通常是借方，因此结清时我们需要贷记这些账户，并将总额借记到留存收益账户。

涉及的费用账户如下：

- **薪资费用 (Salaries and Wages Expense)**：12,850 美元
- **水电费 (Utilities Expense)**：13,216 美元
- **保险费 (Insurance Expense)**：1,390 美元

分录如下：

| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 留存收益 (Retained Earnings) | 27,456 | |
| 薪资费用 (Salaries and Wages Expense) | | 12,850 |
| 水电费 (Utilities Expense) | | 13,216 |
| 保险费 (Insurance Expense) | | 1,390 |

### 步骤三：结清股利账户

第三步是结清股利账户。在本案例中，公司没有派发股利，因此此步骤不适用。

但如果存在股利，其正常余额通常是借方。结清时，我们会贷记股利账户，并借记留存收益账户。假设的分录会是：

| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 留存收益 (Retained Earnings) | [金额] | |
| 股利 (Dividends) | | [金额] |

### 编制结账后试算表

完成所有结账分录后，我们需要编制一份**结账后试算表 (Post-Closing Trial Balance)**。此时，所有的临时账户（收入、费用、股利）余额都已为零，因此它们不会出现在这张试算表上。

结账后试算表只包含**永久账户 (Permanent Accounts)**，即资产、负债和权益。所有临时账户的净影响都被合并到了留存收益这个永久账户中。

在本案例中，留存收益的变动是：贷方增加 48,070 美元（来自收入），借方减少 27,456 美元（来自费用），净增加额为 20,614 美元（贷方）。

其他所有永久账户的余额（如现金、预付物料、设备、递延收入、应付票据、普通股等）直接从调整后试算表复制过来。最终，结账后试算表的借贷方总额应相等，均为 78,180 美元。这张报表比调整后试算表要简洁得多。

### 总结

以上就是编制结账分录的完整流程。这是开启一个新会计期间至关重要的一步，它确保了所有临时账户都被清零，为记录下一年的交易做好了准备。希望这个案例讲解对您有所帮助。
