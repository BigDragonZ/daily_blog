# 财务会计 - 12.4 课 - 间接法 - 经营活动

## 间接法简介

在本节课中，我们将学习如何使用 **间接法 (Indirect Method)** 来编制 **现金流量表 (Statement of Cash Flows)** 的经营活动部分。我们会先讨论相关的理论和操作方法，然后通过一个实例进行演练。

间接法从 **净利润 (Net Income)** 开始，然后通过调整 **非现金支出 (non-cash expenditures)** 以及 **流动资产 (current assets)** 和 **流动负债 (current liabilities)** 的变动，来推导出经营活动的净现金流。这是编制现金流量表经营活动部分最常用的方法，因此掌握它非常重要。

---

## 间接法的操作步骤

使用间接法计算经营活动现金流，通常遵循以下步骤：

1.  **从净利润开始**：这是调整的起点。
2.  **调整损益项目**：对于本入门课程，我们将暂时跳过对出售资产产生的利得 (Gains) 和损失 (Losses) 的调整。这部分内容在更高级的会计课程中会详细讲解。
3.  **加回非现金费用**：将不涉及现金支出的费用（如 **折旧 (Depreciation)** 和 **摊销 (Amortization)**）加回到净利润中。
4.  **调整流动资产和流动负债的变动**：分析资产负债表上流动资产和流动负债的期初和期末余额变动，并对这些变动进行调整。

最终，通过以上调整，我们将净利润调节为经营活动产生的净现金流。

### 为什么加回非现金费用？

以折旧为例。折旧费用每年都会计入损益表，从而减少了净利润。但是，计提折旧时并没有实际的现金流出。购买资产时的现金流出，通常在购买当期作为 **投资活动 (Investing Activity)** 处理，而不是经营活动。

因此，为了从以权责发生制为基础的净利润，推导出以收付实现制为基础的现金流量，我们必须将折旧这类已经从净利润中扣除、但并未导致现金流出的“非现金费用”加回去。

### 流动资产和流动负债的调整规则

在间接法中，对流动资产和流动负债（不包括现金和现金等价物）变动的调整遵循以下核心规则：

-   **流动资产 (Current Assets)**：
    -   **减少**：加回净利润。例如，存货减少意味着销售了一部分之前购买的存货，这部分销售对应的成本（销货成本）虽然减少了利润，但其现金支出发生在过去，本期并未流出现金，因此需要加回。
    -   **增加**：从净利润中减去。例如，应收账款增加意味着公司确认了收入但尚未收到现金，这部分收入增加了净利润，但没有带来现金流入，因此需要减去。

-   **流动负债 (Current Liabilities)**：
    -   **增加**：加回净利润。例如，应付工资增加意味着公司计提了工资费用但尚未支付，该费用减少了净利润，但没有现金流出，因此需要加回。
    -   **减少**：从净利润中减去。例如，应付账款减少意味着公司支付了之前的欠款，导致现金流出，这笔流出并未体现在当期费用中，因此需要减去。

## 案例分析

### 问题描述

假设某公司的损益表显示其净利润为 160 美元，支付了 40 美元的现金股利。其比较资产负债表的部分数据如下：

| 项目 | 期末余额 | 期初余额 |
| :--- | :--- | :--- |
| **流动资产** | | |
| 现金 | | |
| 应收账款 | 300 | 200 |
| 存货 | 250 | 360 |
| **流动负债** | | |
| 应付工资 | 100 | 60 |

请根据以上信息，编制该公司现金流量表的经营活动部分。

### 分析与计算

在编制报表之前，我们首先分析相关账户的变动情况：

1.  **应收账款 (Accounts Receivable)**：从 200 美元增加到 300 美元，**增加了 100 美元**。
2.  **存货 (Inventory)**：从 360 美元减少到 250 美元，**减少了 110 美元**。
3.  **应付工资 (Wages Payable)**：从 60 美元增加到 100 美元，**增加了 40 美元**。

### 编制经营活动现金流量表

现在，我们可以根据间接法的规则来编制报表：

| 项目 | 金额 (美元) |
| :--- | :--- |
| **经营活动现金流** | |
| **净利润** | **160** |
| *对账调整项：* | |
| 存货减少 | 110 |
| 应收账款增加 | (100) |
| 应付工资增加 | 40 |
| **经营活动产生的净现金流** | **210** |

**计算过程**：
`160 (净利润) + 110 (存货减少) - 100 (应收账款增加) + 40 (应付工资增加) = 210 美元`

**说明**：
- **存货减少**：我们加回 110 美元，因为这部分成本对应的现金支出发生在过去，本期销售存货并未导致新的现金流出。
- **应收账款增加**：我们减去 100 美元，因为这部分收入虽然增加了净利润，但公司尚未收到现金。
- **应付工资增加**：我们加回 40 美元，因为这部分费用虽然减少了净利润，但公司尚未支付现金。

最终，该公司由经营活动产生的净现金流为 210 美元。

## 总结

掌握间接法的关键在于理解各项调整背后的逻辑，即如何将权责发生制下的净利润，调整为收付实现制下的现金流量。只要你记住了流动资产和流动负债变动的调整规则，并理解其原因，编制过程就会变得非常简单，如同“即插即用”。

在下一节课中，我们将通过日记账分录的方式，更深入地探讨为什么需要进行这些加减调整，从而帮助你从根本上理解这些规则。
