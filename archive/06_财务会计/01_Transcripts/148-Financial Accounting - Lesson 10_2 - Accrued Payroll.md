## 员工工资的核算

本节课我们将讨论工资核算 (Payroll)，特别是从雇主 (Employer) 的角度来探讨。我们通常是领取工资单 (Paycheck) 的一方，但雇主在其账簿上是如何记录这笔交易的呢？当公司向员工发放薪水时，问题就在于他们如何在自己的账簿上进行记录。我们将逐步分解员工工资单的构成，包括各项扣除，并最终完成相应的会计分录。

## 核心工资术语

当公司向员工发放薪水时，并不会直接支付员工赚取的全部金额。根据联邦或州法律，公司必须计算并代扣工资扣除款。这些款项随后需要上缴给政府机构或其他公司。

- **应发工资 (Gross Earnings / Gross Pay)**：指员工在特定时期内赚取的总金额。对于**时薪制员工 (hourly employees)**，其计算方式为“工作小时数 × 每小时费率”。例如，工作 10 小时，时薪 15 美元，则应发工资为 150 美元。对于**月薪制员工 (salary employees)**，通常是将其年薪除以年度发薪次数。例如，年薪 12 万美元，每月发薪一次，则每月的应发工资为 1 万美元。

- **工资扣除 (Payroll Deductions)**：指从员工应发工资中扣除的所有项目，这些扣除项也被称为**预扣款 (withholdings)**。这些扣除项减少了应发工资，使其变为员工实际收到的金额。

- **实发工资 (Net Pay)**：也称为“净工资”，是员工在所有预扣款项被扣除后，实际收到的金额。计算公式为：**应发工资 - 工资扣除 = 实发工资**。

## 工资单示例解析

让我们通过一张工资单来具体分析。这张工资单显示，该员工为时薪制，费率为每小时 37 美元，本期工作了 40 小时。因此，他的应发工资为 1,480 美元 (37 × 40)。

接下来是扣除项。这些扣除分为法定强制扣除和员工自愿选择的扣除。

- **员工税费预扣 (Employee Taxes Withheld)**：
    - 联邦所得税 (Federal Income Tax): \$120.78
    - 社会保障税 (Social Security): \$91.76
    - 医疗保险税 (Medicare): \$21.46
    - 加州所得税 (California State Income Tax): \$27.37
    - 加州伤残保险 (California State Disability Insurance): \$14.80

- **其他员工扣除 (Other Employee Deductions)**：
    - 401(k) 退休金计划: \$103.60

在工资单的摘要部分，我们可以看到：应发工资为 1,480 美元，减去税前扣除（401k 缴款）103.60 美元，再减去税费 276.17 美元，最终的**实发工资 (Net Pay) 为 1,100.23 美元**。这意味着从员工的应发工资中总共扣除了约 380 美元。

## 主要扣除项详解

- **所得税预扣 (Income Tax Withholdings)**：这通常是工资单上最大的一笔扣除。需要强调的是，这笔钱只是对员工年底应缴所得税的**预估和预缴**，并非最终的实际税额。年底员工报税时，会根据全年总收入和预缴总额进行清算，可能需要补税或获得退税。

- **FICA 税**：这是**联邦保险贡献法案 (Federal Insurance Contributions Act, FICA)** 的简称，包含两个部分：
    - **社会保障税 (Social Security)**：为员工提供退休福利。税率通常为应发工资的 6.2%，但设有年度收入上限，超过上限的收入部分不再征收。
    - **医疗保险税 (Medicare)**：为年长者和部分残障人士提供国家健康保险。税率为应发工资的 1.45%，**没有收入上限**。

- **州及其他扣除项**：
    - **州级扣除 (State Deductions)**：根据所在州的不同，可能包括州所得税、州伤残保险等。
    - **其他自愿扣除 (Other Deductions)**：这些通常是员工自愿选择的项目，例如：
        - **退休金计划**：如 401(k) 账户的个人缴款。
        - **医疗保险**：支付健康、牙科和视力保险的保费。
        - **其他保险**：如人寿保险、癌症护理保险或短期残疾保险。
        - **慈善捐款**：通过公司统一向慈善机构捐款。
        - **预支工资还款**：偿还之前从公司预支的薪水。

## 扣除项的会计处理：负债

对于公司而言，从员工工资中扣除的这些款项并非公司的收入。公司只是代为保管，并有义务在规定时间内将这些资金支付给相应的机构（如税务局、401(k) 管理公司等）。因此，所有这些预扣款在公司的账簿上都应被记录为**负债 (Liabilities)**。

## 工资的日记账分录

现在，让我们为之前分析的工资单制作一笔日记账分录 (Journal Entry)。虽然公司通常会汇总所有员工的工资信息做一笔总分录，但为了便于理解，我们只针对这一张工资单进行处理。

这笔分录的核心是确认全部劳动成本（应发工资）为费用，同时确认所有扣除项和应付给员工的净工资为负债。

| 日期       | 账户                               | 借方 (Debit) | 贷方 (Credit) |
| ---------- | ---------------------------------- | ------------ | ------------- |
| [Date]     | 薪资费用 (Salaries and Wages Expense) | \$1,480.00   |               |
|            | 联邦所得税应付款 (Federal Income Tax Payable) |              | \$120.78      |
|            | FICA 税应付款 (FICA Tax Payable)     |              | \$113.22      |
|            | 州预扣税应付款 (State Withholdings Payable) |              | \$42.17       |
|            | 退休金应付款 (Retirement Payable)    |              | \$103.60      |
|            | 应付工资 (Wages Payable)             |              | \$1,100.23    |
|            | *记录本期工资费用及相关负债*         |              |               |

**分录说明**：
- **借记“薪资费用”**：金额为应发工资总额（1,480 美元），这代表公司在本期发生的真实人工成本。
- **贷记各项“应付款”**：这些是公司代扣的款项，是公司欠第三方（政府、退休金管理人等）的债务。
- **贷记“应付工资”**：金额为员工的实发工资（1,100.23 美元）。这代表公司欠员工的、即将支付的款项。如果公司在记录分录的当天就支付了工资，也可以直接贷记“现金 (Cash)”。通常，工资计算和发放之间有时间差，因此使用“应付工资”更为普遍。

## 总结

本节课我们详细探讨了应计工资的核算。核心在于理解从应发工资到实发工资的计算过程，识别各种扣除项的性质，并最终通过一笔日记账分录，准确地将工资费用和因此产生的所有负债记录到公司的账簿中。
