# 财务会计 - 8.7 - 坏账准备费用示例

在这节课中，我们将通过一个实例来讲解坏账备抵法 (Allowance Method for Bad Debt)。我们会引导你完成所有相关步骤，从计算坏账准备金的数额，到最终确定坏账费用 (Bad Debt Expense)。

整个过程分为四个步骤：
1.  **准备应收账款账龄分析表 (AR Aging Listing)**：我们将根据最坏的情况，即需要自己从头开始创建这个表。通常，账龄会划分为 0-30 天、31-60 天、61-90 天以及 90 天以上等区间。
2.  **确定各账龄区间的坏账损失率**：这些百分比通常是给定的，我们会将其应用到账龄分析表中。
3.  **计算预期的坏账准备总额**：利用前两步的信息，计算出期末坏账准备账户应有的余额。
4.  **计算坏账费用并作账**：第三步计算出的金额**不是**直接的坏账费用。我们需要将它与坏账准备账户的现有余额进行比较，差额才是本期应计提的坏账费用，并据此进行相应的日记账分录 (Journal Entry)。

---

### 案例分析

公司 A 采用账龄分析法来估算坏账费用。其应收账款根据账龄分为三个区间：
- **1-30 天**：$11,000
- **31-90 天**：$4,000
- **90 天以上**：$2,000

根据历史经验，各个账龄区间的平均坏账损失率估计如下：
- **1-30 天**：6%
- **31-90 天**：12%
- **90 天以上**：20%

在年底（12月31日）进行调整分录之前，坏账准备 (Allowance for Doubtful Accounts) 账户有 $700 的贷方余额 (Credit Balance)。

**要求**：
1.  编制一个表格，估算年末坏账准备的适当余额。
2.  计算在 12 月 31 日应记录的坏账费用金额。

---

### 步骤一 & 步骤二：准备账龄分析表并应用损失率

首先，我们创建一个表格来整理信息。表格包括应收账款金额、各区间的坏账损失率以及预计无法收回的金额。

| 描述 | 1-30 天 | 31-90 天 | 90 天以上 | 总计 |
| :--- | :--- | :--- | :--- | :--- |
| **应收账款 (AR)** | $11,000 | $4,000 | $2,000 | $17,000 |
| **预计坏账率** | 6% | 12% | 20% | (不适用) |
| **预计坏账金额** | ? | ? | ? | ? |

注意，总计栏的坏账率没有意义，因为我们不能简单地将不同区间的比率相加。

### 步骤三：计算期末应有的坏账准备余额

接下来，我们将每个账龄区间的应收账款金额乘以其对应的坏账率，以计算预计的坏账金额。

- **1-30 天**: $11,000 \times 6\% = \$660$
- **31-90 天**: $4,000 \times 12\% = \$480$
- **90 天以上**: $2,000 \times 20\% = \$400$

将所有区间的预计坏账金额相加，得出期末坏账准备账户应有的余额：
$660 + 480 + 400 = \$1,540$

这意味着，在总计 $17,000 的应收账款中，我们预计有 $1,540 将无法收回。这个 $1,540 就是我们坏账准备账户在期末应该达到的目标余额。

值得注意的是，账龄越长，坏账的风险越高，因此对应的坏账率也越高（从 6% 上升到 20%）。这是符合逻辑的，因为一笔欠款拖欠的时间越久，收回的可能性就越小。

### 步骤四：计算坏账费用并编制调整分录

我们已经计算出坏账准备账户的期末目标余额为 $1,540（贷方）。而在调整前，该账户已有 $700 的贷方余额。为了使账户余额从 $700 增加到 $1,540，我们需要补提的差额就是本期的坏账费用。

- **目标余额**：$1,540 (贷方)
- **期初余额**：$700 (贷方)
- **需补提金额 (坏账费用)**：$1,540 - 700 = \$840$

因此，本期应记录的坏账费用为 $840。对应的调整分录如下：

| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 坏账费用 (Bad Debt Expense) | $840 | |
| 坏账准备 (Allowance for Bad Debt) | | $840 |

通过这笔分录，坏账准备账户的最终余额将变为 $700 + 840 = \$1,540，达到了我们预期的目标。

### 特殊情况：如果期初为借方余额

让我们考虑一种特殊情况：如果在调整前，坏账准备账户的余额是 $700 的**借方余额 (Debit Balance)**，这意味着之前冲销的坏账超出了预期。

在这种情况下，要使账户余额达到 $1,540 的贷方目标，我们不仅要填补 $700 的“窟窿”，还要额外计提 $1,540。

- **从 $700 (借方) 恢复到 0**：需要贷记 $700。
- **从 0 增加到 $1,540 (贷方)**：需要贷记 $1,540。

总共需要贷记的金额为：$700 + 1,540 = \$2,240$。

此时，坏账费用就是 $2,240，调整分录为：

| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 坏账费用 (Bad Debt Expense) | $2,240 | |
| 坏账准备 (Allowance for Bad Debt) | | $2,240 |

这种情况说明本年度的实际坏账情况比最初估计的要严重，但只要调整方法正确，会计处理依然是合理的。
