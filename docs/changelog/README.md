# 更新记录（Changelog）

每次开发完成后在此目录新增一条记录，文件名格式：`YYYY-MM-DD-主题.md`。

## 目录规范

- 网站页面：`pages/<学科>/<课程>/<章节>.html`
- 公共资源：`assets/css/`、`assets/js/`（图表统一复用 `assets/js/charts.js`）
- 菜单数据：`assets/js/menu.js`（新增章节时在 `MENU` 中追加节点）
- 已学习完的原始资料：`archive/`
- 更新记录：本目录
