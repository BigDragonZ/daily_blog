# 财务会计 - 课程 2.2 - 扩展的会计等式

---

在本课程中，我们将帮助您学习和理解**扩展的会计等式 (Expanded Accounting Equation)**。在之前的课程中，我们讨论了基本的会计等式：**资产 (Assets) = 负债 (Liabilities) + 所有者权益 (Owner's Equity)**。这个基础等式非常重要，您需要掌握它。然而，还有一个更佳的等式，可以帮助我们处理交易。您可以将这个新等式视为一个“密钥”，一旦掌握，就能应用于每一笔交易，最终帮助我们完成**日记账分录 (Journal Entries)**，这也是本课程在微观层面上的核心内容。

回顾一下，在第一部分中我们学习了两个等式。第一个是**基本会计等式**：`资产 = 负债 + 股东权益 (Shareholders' Equity)`。第二个是**权益等式 (Equity Equation)**，它具体阐述了股东权益的构成：

> **股东权益 = 所有者资本 (Owner's Capital) - 股利 (Dividends) + 收入 (Revenue) - 费用 (Expenses)**

其中，所有者资本是所有者对公司的财务或资产投入；股利是所有者从公司取回的资金，因此需要减去；而收入减去费用就是**净利润 (Net Income)**。

在代数学习中，当两个等式有共同变量时，我们可以将它们合并为一个。在我们的例子中，两个等式都包含**股东权益**这一项。因此，我们可以将权益等式的右侧部分，直接代入到基本会计等式中“股东权益”的位置。由于只涉及加减法，这个过程非常简单，就像复制粘贴一样。合并后，我们得到如下的扩展会计等式：

> **资产 = 负债 + 所有者资本 - 股利 + 收入 - 费用**

这个扩展等式虽然完整，但其中包含减号，这在记忆和使用时可能会带来不便。根据代数原理，我们可以将等式右边的负数项（减项）移动到等式左边，使它们变为正数项（加项）。具体来说，我们将“- 股利”和“- 费用”从右边移到左边，得到一个所有项都为正的等式：

> **股利 + 费用 + 资产 = 负债 + 所有者资本 + 收入**

为了方便长期记忆，我们可以使用一个助记词。取等式左侧每一项的英文首字母 **D** (Dividends), **E** (Expenses), **A** (Assets)，和等式右侧每一项的英文首字母 **L** (Liabilities), **O** (Owner's Capital), **R** (Revenue)，我们可以得到 **DEALOR** 这个词。这个助记词代表了最终的、也是最实用的扩展会计等式形式：

> **D** (股利) + **E** (费用) + **A** (资产) = **L** (负债) + **O** (所有者资本) + **R** (收入)

虽然基本会计等式和扩展会计等式都有用，但在进行交易分析时，**DEALOR** 形式的扩展等式对于理解**借方 (Debits)** 和**贷方 (Credits)** 更有帮助。很多人习惯使用基本等式，但为了更好地学习日记账分录，您需要知道如何从基本等式转换到 **DEALOR** 等式。

我必须再次强调这个等式的重要性，特别是对于初学者而言。掌握日记账分录是学习会计的关键，而理解 **DEALOR** 等式是掌握分录的第一步。如果你能理解这个等式，你就能理解如何做分录；如果你能做好分录，那么本课程后续的大部分内容你都能轻松应对。因为很多会计问题都基于“如何为这笔交易做分录”这个基础之上。所以，请务必掌握 **DEALOR** 等式：**股利 + 费用 + 资产 = 负债 + 所有者资本 + 收入**。
