# 财务会计 - 第 11.2 课 - 理解普通股

## 股票发行的法律基础

在本课程中，我们将探讨普通股 (Common Stock)，希望能帮助你理解其基本概念以及它在公司层面上是如何产生的。

公司根据其向经营所在州提交的 **公司章程 (Corporate Charter)** 来发行股票。这是一个由各州管理的事项。公司不能凭空创造股票，而是必须向公司成立所在州的州务卿提交文件。许多公司选择在 **特拉华州 (Delaware)** 注册，因为那里的流程相对简单，且商业环境友好。在公司章程中，公司会明确说明希望拥有发行权的股票数量。

公司章程将指明公司可以发行的最大股票数量。州政府通常不会修改公司提交的股票数量，只要公司支付了相关费用并满足所有备案要求，申请通常就会被批准。

## 普通股的四个关键术语

关于普通股，有四个关键术语需要理解：**核准发行 (Authorized)**、**已发行 (Issued)**、**库藏股 (Treasury)** 和 **流通在外 (Outstanding)**。我们会逐一解释，因为它们在普通股的语境中各自代表不同的含义。

### 1. 核准发行 (Authorized)

**核准发行股** 是指根据公司章程，公司被允许发行的最大股票数量。如果章程规定了 1000 万股，那么这就是公司被授权发行的最高限额。未经章程修订，公司不能超额发行。这并不意味着公司会立即发行所有这些股票，它更像是一个可供发行的股票“储备池”。

### 2. 已发行 (Issued)

在核准发行的总额中，公司会决定实际发行多少股票。**已发行股** 代表公司已经出售或分配给股东的股票数量。通常，已发行股数会少于或等于核准发行股数。公司通常不会一次性发行所有核准的股票，因为保留一部分未发行的股票以备未来融资需求是更为明智的做法。

### 3. 库藏股 (Treasury Stock)

**库藏股** 是指公司回购的、已经发行在外的股票。这些股票曾被发行，但现在由公司自己持有。公司回购股票后，可以选择将其 **注销 (Retire)**，即永久销毁，也可以作为库藏股持有。库藏股仍然是已发行股的一部分，但它们不属于流通在外的股票，因为公司不能持有自己的所有权。这种回购行为通常被称为 **股票回购 (Stock Buyback)**。持有库藏股使公司可以在未来重新将其出售到市场。

### 4. 流通在外 (Outstanding)

**流通在外股** 是指由股东（而非公司本身）持有的已发行股票。这是股票进入投资者手中的最常见状态。当你作为一名股东持有某公司的股票时，这些股票就是流通在外的。

## 示例分析

假设一家公司被 **核准发行** 1000 万股股票。该公司已经 **发行** 了 300 万股，其中目前有 280 万股 **流通在外**。那么，该公司持有多少 **库藏股** 呢？

- **核准发行总数**: 1000 万股。这是一个上限，代表了公司可发行的最大潜力。
- **已发行股数**: 300 万股。这是已经从“储备池”中取出发行的部分。
- **未发行股数**: 1000 万 - 300 万 = 700 万股。这些股票仍可供未来发行。

已发行的 300 万股分为两部分：一部分由外部股东持有（流通在外），另一部分由公司自己回购持有（库藏股）。

- **流通在外股数**: 280 万股。
- **库藏股数**: 已发行股数 - 流通在外股数 = 300 万 - 280 万 = 20 万股。

因此，该公司持有 20 万股库藏股。我们可以验证：流通在外股数 (280万) + 库藏股数 (20万) = 已发行股数 (300万)。

## 总结

本节课我们重点理解了普通股的四个核心术语：**核准发行 (Authorized)**、**已发行 (Issued)**、**库藏股 (Treasury)** 和 **流通在外 (Outstanding)**。掌握这些术语及其相互关系，是理解公司股权结构的基础。在后续课程中，我们会频繁使用这些概念。
