### 问题描述

我们将通过一个具体辨认法 (Specific Identification) 的例子来学习。

A 公司是一家批发商，从本地制造商处购买机器，然后直接销售给客户。A 公司采购了五台机器（A 到 E）用于销售，其成本和售价信息如下表所示。

| 机器编号 | 成本 (Cost) | 售价 (Sales Price) |
| :--- | :--- | :--- |
| A | $12,500 | $20,000 |
| B | $12,800 | $21,000 |
| C | $13,500 | $22,500 |
| D | $14,350 | $24,000 |
| E | $15,800 | $26,000 |
| **总计** | **$68,950** | |

在一月份，A 公司售出了两台机器：机器 B 和机器 D。

**要求：**
1. 计算一月份的销售成本 (Cost of Goods Sold, COGS)。
2. 计算期末库存 (Ending Inventory) 价值。
3. 计算这两笔销售的毛利润 (Gross Profit)。
4. 编制一月底需要记录的日记账分录 (Journal Entry)。

### 计算销售成本、期末库存与毛利润

1.  **销售成本 (Cost of Goods Sold, COGS)**
    由于我们使用具体辨认法，我们需要将售出商品的具体成本从库存中转出。本例中，售出的是机器 B 和机器 D。因此，销售成本是这两台机器的成本之和：
    `$12,800 (机器 B 成本) + $14,350 (机器 D 成本) = $27,150`
    所以，一月份的销售成本为 **$27,150**。

2.  **期末库存 (Ending Inventory)**
    期末库存的价值是所有未售出机器的成本总和。在本例中，机器 A、C 和 E 仍未售出。
    `$12,500 (机器 A) + $13,500 (机器 C) + $15,800 (机器 E) = $41,800`
    或者，我们也可以用初始总库存成本减去销售成本来计算：
    `$68,950 (总库存成本) - $27,150 (COGS) = $41,800`
    因此，期末库存价值为 **$41,800**。

3.  **毛利润 (Gross Profit)**
    毛利润的计算公式为：总销售收入 (Total Sales Revenue) - 销售成本 (COGS)。
    - **总销售收入**：售出的机器 B 和 D 的销售价格之和。
      `$21,000 (机器 B 售价) + $24,000 (机器 D 售价) = $45,000`
    - **毛利润**：
      `$45,000 (总销售收入) - $27,150 (COGS) = $17,850`
    因此，毛利润为 **$17,850**。

### 日记账分录 (Journal Entries)

对于每笔销售，通常需要记录两笔分录：一笔记录销售收入，另一笔记录销售成本。

1.  **记录销售收入**
    这笔分录记录了从客户那里获得的资产（假设为现金）和实现的收入。
    - **借 (Debit)**: 现金 (Cash)  $45,000
    - **贷 (Credit)**: 销售收入 (Sales Revenue)  $45,000
    *(记录销售机器 B 和 D 所得的收入)*

2.  **记录销售成本**
    这笔分录将售出商品的成本从资产（库存）转为费用（销售成本）。
    - **借 (Debit)**: 销售成本 (Cost of Goods Sold)  $27,150
    - **贷 (Credit)**: 库存 (Inventory)  $27,150
    *(记录售出机器 B 和 D 的成本)*

### 总结

具体辨认法的核心在于将售出的每一件特定商品的成本与其销售进行精确匹配。这种方法不依赖于成本流假设（如先进先出 FIFO 或后进先出 LIFO），而是追踪实际的物理流程。正因如此，它最适用于库存量少、单位价值高且易于通过序列号等方式进行单独追踪的商品，例如汽车、珠宝或大型机械。只要你能一步步耐心计算，这个方法本身并不复杂。
