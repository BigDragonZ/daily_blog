### 应付票据 (Notes Payable) 概述

本节课我们将讨论**应付票据 (Notes Payable)**，回顾一些已知概念，并详细介绍如何将其计入账簿。

应付票据是一种正式的债务形式，债务人签署票据，承诺向债权人 (creditor) 偿还到期债务。它通常是书面形式，涉及签名，比普通的**应付账款 (Accounts Payable)** 更为正式。应付票据的一个关键特征是包含利息，这也是本节课的重点。我们将学习如何计算利息，并在利息费用到期或偿还票据时进行账务处理。

### 应付票据的两种偿还方式

通常，应付票据的差异在于本金的偿还方式，主要分为两种类型：

1.  **一次性总付 (Lump Sum)**：在这种模式下，借款的全部**本金 (principal)** 在票据到期时一次性偿还。例如，如果公司借入一百万美元，期限为五年，那么公司在五年期末才需要偿还这一百万美元的本金。在此期间，利息仍会产生并需要定期支付（例如每六个月），但本金在到期前无需偿还。
2.  **年金 (Annuity)**：在这种模式下，本金和利息在票据的整个期限内分期定期偿还。一个常见的例子是汽车贷款。每次还款时，不仅支付了利息，还偿还了一部分本金。因此，在贷款期末，不会有一笔巨额的本金需要支付。

本课程将主要关注**一次性总付**模式的应付票据。

### 应付票据的生命周期

应付票据的生命周期中通常涉及四个关键的会计事件：

- **设立票据**：记录初始借款的日记账分录。
- **计提利息**：在会计期末，为已发生但尚未支付的利息进行计提。
- **支付利息**：记录支付利息的交易。
- **偿还票据**：在票据到期时，记录偿还本金的交易。

### 案例分析

接下来，我们将通过一个例子来演示上述四个步骤的完整流程。

> 假设A公司在 **20X1年10月1日** 从银行获得一张为期一年、金额为 **$100,000**、年利率为 **5%** 的票据。公司的会计年度截止日期为 **20X1年12月31日**。请准备与该票据相关的所有交易分录。

根据案例信息，这张票据于20X1年10月1日生效，一年后即20X2年9月30日到期。由于公司的结账日在12月31日，我们需要在20X1年底计提当年的利息费用，以确保费用与发生的期间相匹配。

#### 第一步：设立票据 (20X1年10月1日)

当公司收到借款时，我们获得了 $100,000 现金，同时产生了一项偿还债务的义务。因此，我们需要增加现金资产和应付票据负债。

- **借记 (Debit)**：**现金 (Cash)**，因为资产增加。
- **贷记 (Credit)**：**应付票据 (Notes Payable)**，因为负债增加。

日记账分录如下：

```
借：现金 (Cash)  $100,000
  贷：应付票据 (Notes Payable)  $100,000
```

#### 第二步：计提期末利息 (20X1年12月31日)

到20X1年底，这张票据已经存在了三个月（十月、十一月、十二月）。根据权责发生制，我们需要将这三个月的利息费用记录在20X1年。

利息的计算公式为：
**利息 = 票据面值 × 年利率 × 时间（年度比例）**

除非特别说明，利率通常指年利率。

- **计算20X1年的利息**：
  $100,000 × 5% × (3 / 12) = $1,250

这 $1,250 是20X1年应承担的借款成本。由于这笔利息尚未支付，我们将其记录为一项费用和一项应付负债。

日记账分录如下：

```
借：利息费用 (Interest Expense)  $1,250
  贷：应付利息 (Interest Payable)  $1,250
```

#### 第三步与第四步：支付利息与偿还本金 (20X2年9月30日)

在票据到期日，公司需要支付全部利息并偿还本金。

首先，计算20X2年产生的利息。从20X2年1月1日到9月30日，共9个月。

- **计算20X2年的利息**：
  $100,000 × 5% × (9 / 12) = $3,750

在到期日，公司需要支付的**总利息现金**为20X1年和20X2年利息的总和：
$1,250 (20X1年) + $3,750 (20X2年) = $5,000

支付利息和偿还本金的日记账分录如下：

1.  **记录利息支付**：
    我们需要核销去年计提的**应付利息**，确认今年的**利息费用**，并减少**现金**。

    ```
    借：利息费用 (Interest Expense)  $3,750
    借：应付利息 (Interest Payable)  $1,250
      贷：现金 (Cash)  $5,000
    ```
    这个分录确保了20X2年的财务报表只反映当年产生的 $3,750 利息费用，同时清除了账上的应付利息负债。

2.  **记录本金偿还**：
    公司支付 $100,000 现金以解除应付票据的义务。

    ```
    借：应付票据 (Notes Payable)  $100,000
      贷：现金 (Cash)  $100,000
    ```
    借记应付票据会减少负债，贷记现金会减少资产。

通过以上步骤，我们完成了应付票据从设立到偿还的整个生命周期的会计处理。希望本节课能帮助你更好地理解应付票据的核算方法。
