# 财务会计 - 4.1 课 - 调整分录入门

欢迎来到第四部分，我们将在这里讨论**调整分录 (Adjusting Entries)**。调整分录是会计师在期末进行的一项流程，用以确保账簿准确地反映期末的收入和费用。在本节中，我们将向您展示如何通过编制日记账分录来调整账目，以确保在利润表上正确报告收入和费用。

### 调整分录的重要性

调整分录之所以重要，是因为我们使用**权责发生制会计 (Accrual Accounting)**。在权责发生制下，现金的收付时间可能先于或晚于收入或费用的确认时间。因此，我们的账簿可能无法达到最准确的状态，因为实际的现金交易尚未发生。这时就需要进行调整，以决定是否应该确认某项收入或费用，这取决于它是否已经赚取或发生。在本节的最后，我们还将学习**结账分录 (Closing Entries)**，它能帮助我们将账簿准备好，以迎接下一个会计年度。

### 调整分录的基本原则

调整分录是会计循环中在期末进行的一项工作，旨在根据整个会计期间发生的交易，更新公司的账簿，确保期末账目是最新且准确的。这不是会计师每天都会做的事情，而是在月末或年末集中进行。

在学习本节内容时，您需要记住一个关键点：**现金 (Cash) 永远不会成为调整分录的一部分**。如果您在分录中看到现金，那它就不是调整分录。调整分录涉及的是除现金以外的所有账户。当然，在调整之前或之后的交易中可能会涉及现金，但调整分录本身在调整日进行时，不涉及现金交易。

### 如何进行调整：一个实例

理解调整过程的关键在于分析账户。假设我们来看**递延收入 (Deferred Revenue)** 这个账户，它是一种负债，表示客户预先支付了现金，而我们尚未提供相应的服务或商品。

假设我们的递延收入账户目前有 4000 美元的余额。经过分析，我们发现根据已履行的服务，该账户的余额现在应该是 2000 美元。这意味着，在原有的 4000 美元中，我们已经通过提供服务赚取了 2000 美元。因此，调整的过程就是计算账户当前余额（4000美元）与应有余额（2000美元）之间的差额。这个 2000 美元的差额，就是我们需要在调整期内进行的调整金额。我们会将这部分金额从递延收入转为已实现的服务收入。

### 为何需要调整分录？

调整分录是必要的，主要有以下几个原因：

1.  **收入的正确归属**：确保收入在其赚取的会计期间内被记录，而不是在收到现金时。例如，一项在 20X1 年完成的服务，即使在 20X2 年才收到款项，其收入也应记录在 20X1 年。
2.  **费用的正确配比**：确保费用在其发生的会计期间内被记录，而不是在支付现金时。例如，即使年底还未收到电费账单，我们也需要估算并记录当期已发生的电费。
3.  **资产的准确反映**：确保资产账户能准确反映其在特定时间点所拥有的经济利益。例如，我们已提供服务但尚未收款，就应将这笔应收账款计入资产。
4.  **负债的准确反映**：确保负债账户能准确反映公司在特定时间点所欠的债务。例如，年底前已使用的水电费，即使账单次年才到，也应确认为一项负债。

### 调整分录的两大类型

所有的调整分录可以分为两大类：**应计 (Accruals)** 和 **递延 (Deferrals)**。

1.  **应计 (Accruals)**：
    *   **应计费用 (Accrued Expenses)**：指费用已经发生，但尚未支付现金。
    *   **应计收入 (Accrued Revenue)**：指收入已经赚取，但尚未收到现金。

2.  **递延 (Deferrals)**：
    *   **递延费用 (Deferred Expenses)**：指现金已经支付，但费用尚未发生（例如预付租金）。
    *   **递延收入 (Deferred Revenue)**：指现金已经收到，但收入尚未赚取（例如客户预付款）。

在接下来的课程中，我们将详细讲解如何为这四种情况编制调整分录。实际上，其中一些分录您在第三部分中已经接触过。

### 总结

调整分录对许多学生来说有些困难，因为它不像其他交易那样有明确的原始凭证（如发票）来触发。它需要我们思考在过去一段时间里发生了什么，从而判断是否需要进行调整。在后续的课程中，我会分解每个案例，向您展示如何处理调整，并提供一个通用的分录“蓝图”。一旦您掌握了这个蓝图，处理各种调整交易就会变得像“即插即用”一样简单。希望您喜欢这次关于调整分录的介绍，我们下节课再见。
