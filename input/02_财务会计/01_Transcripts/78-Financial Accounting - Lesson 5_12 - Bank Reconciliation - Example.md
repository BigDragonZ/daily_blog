# 财务会计 - 5.12 课 - 银行对账 - 示例

## 课程简介

本节课我们将通过一个具体的例子来学习如何进行**银行对账 (Bank Reconciliation)**。这是一个相对简单的示例，旨在帮助你理解整个流程。

在更复杂的场景中，你可能不会直接得到所有调整项的数字，而是需要通过对比公司开出的支票清单和银行已兑现的支票清单，自行找出差异。你需要将公司账簿上与银行对账单上相符的项目逐一核对并划掉，账簿上剩下未被划掉的支票就是**未兑现支票 (Outstanding Checks)**。同样地，对比两边的存款记录，账簿上多出的存款就是**在途存款 (Deposits in Transit)**。而银行对账单上出现但账簿上没有的项目，则需要对公司账簿进行调整。

不过，在本例中，我们已经为你整理好了这些差异项目，让你能更专注于对账本身的逻辑。

---

## 案例背景：唐娜日托中心 (Donna Day Care)

请为唐娜日托中心 (Donna Day Care) 准备银行对账表，已知信息如下：

- **银行对账单显示的现金余额**：$5,586
- **公司账簿（总分类账）显示的现金余额**：$5,055
- **未兑现支票 (Outstanding Checks)**：总计 $1,816
- **在途存款 (Deposits in Transit)**：$750
- **存款不足支票 (Non-Sufficient Funds, NSF)**：一张被退回的支票，金额为 $450
- **银行利息收入**：$15
- **支票记账错误**：第 800 号支票用于支付**应付账款 (Accounts Payable)**，银行正确兑现了 $1,100，但公司账簿错误地记为 $800。
- **银行存款错误**：公司一笔 $6,000 的存款被正确记录在账簿上，但银行错误地将其记为 $6,200。

## 银行对账表演示

我们将按照七个步骤来完成这份银行对账表。对账表通常分为左右两部分，左边是“银行方”调整，右边是“账簿方”调整。我们的目标是让两边的最终余额相等。

### 银行对账表 (Bank Reconciliation)
### 截至 2019 年 6 月 30 日

| 银行方 (Bank Side) | 账簿方 (Book Side) |
| :--- | :--- |
| **期末银行结单余额** | **$5,586** | **期末账簿余额** | **$5,055** |
| **加：** | | **加：** | |
| 在途存款 | $750 | 银行利息收入 | $15 |
| **减：** | | **减：** | |
| 未兑现支票 | ($1,816) | 存款不足支票 (NSF) | ($450) |
| 银行存款错误 | ($200) | 支票记账错误 | ($300) |
| **调整后现金余额** | **$4,320** | **调整后现金余额** | **$4,320** |

## 详细步骤解析

### 第一步：填列期初余额

首先，我们将银行对账单和公司账簿各自的期末余额填入对账表的起始位置。
- **银行方余额**：$5,586
- **账簿方余额**：$5,055

### 第二步：调整未兑现支票 (Outstanding Checks)

- **谁知道这件事？** 公司知道，因为是公司开出的支票。
- **谁不知道？** 银行不知道，因为持有支票的人还没有去银行兑现。
- **当银行知道后会怎样？** 银行会从我们的账户中扣款。
- **结论**：我们需要在“银行方”的余额中**减去**这笔未来将发生的支出。因此，在银行方扣除 $1,816。

### 第三步：调整在途存款 (Deposits in Transit)

- **谁知道这件事？** 公司知道，因为是公司存的款。
- **谁不知道？** 银行不知道，因为这笔存款可能还在处理过程中，尚未记入账户。
- **当银行知道后会怎样？** 银行会增加我们账户的余额。
- **结论**：我们需要在“银行方”的余额中**加上**这笔即将到账的存款。因此，在银行方增加 $750。

### 第四步：调整存款不足支票 (NSF Check)

- **谁知道这件事？** 银行知道，因为银行在处理客户支票时发现对方账户余额不足。
- **谁不知道？** 公司在收到银行通知前不知道。我们之前收到这张支票时，已经增加了账上的现金。
- **当我们知道后会怎样？** 我们需要将之前增加的现金减掉，因为它实际上并未到账。
- **结论**：我们需要在“账簿方”的余额中**减去**这笔空头支票的金额。因此，在账簿方扣除 $450。

### 第五步：调整银行利息收入

- **谁知道这件事？** 银行知道，因为是银行支付给我们的利息。
- **谁不知道？** 公司在看到对账单前不知道。
- **当我们知道后会怎样？** 我们会增加账上的现金余额，因为这是一笔收入。
- **结论**：我们需要在“账簿方”的余额中**加上**这笔利息收入。因此，在账簿方增加 $15。

### 第六步：调整各类错误

错误的调整原则是：**谁错了，就调整谁**。

1.  **支票记账错误**：
    - **错误情况**：支票实际金额为 $1,100，但公司账簿只记了 $800，少记了 $300 的支出。
    - **谁错了？** 公司错了。
    - **如何更正？** 公司需要补记这 $300 的支出，这会减少现金。
    - **结论**：在“账簿方”**减去**差额 $300。

2.  **银行存款错误**：
    - **错误情况**：公司实际存款 $6,000，但银行错误地记入了 $6,200，多记了 $200。
    - **谁错了？** 银行错了。
    - **银行发现后会怎样？** 银行会从我们的账户中扣除多记的 $200。
    - **结论**：我们需要在“银行方”**减去**这个差额 $200，以反映银行未来会进行的更正。

### 第七步：计算最终余额

现在，我们分别计算两边的最终余额：

- **银行方调整后余额**：
  $5,586 (期初) + $750 (在途存款) - $1,816 (未兑现支票) - $200 (银行错误) = **$4,320**

- **账簿方调整后余额**：
  $5,055 (期初) + $15 (利息) - $450 (NSF 支票) - $300 (账簿错误) = **$4,320**

两边最终的“调整后现金余额”完全相等，均为 $4,320。这表明我们的银行对账工作已经成功完成。如果最终数字不匹配，你就需要像侦探一样，用放大镜仔细检查每一步，找出可能存在的错误。

## 总结

希望通过这个例子，你对银行对账的流程有了清晰的理解。在实际操作中，最耗时的部分往往是找出所有的差异项。一旦找到了它们，遵循“谁不知道就调整谁”和“谁错了就调整谁”的原则，就能顺利完成对账。
