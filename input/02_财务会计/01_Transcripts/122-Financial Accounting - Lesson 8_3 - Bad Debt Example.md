# 财务会计 - 8.3课 - 坏账示例

在本节课中，我们将通过一个简单的例子，向您展示如何为**坏账 (Bad Debt)** 做**会计分录 (journal entries)**。如果您看过上一节课，应该已经了解了相关的分录。现在，我们通过一个具体案例来演示这些分录在实际中是如何操作的。本课会直接给出所有金额，在后续课程中，我们将详细讲解如何计算这些数额。

A 公司根据其**注册会计师 (CPA)** 的建议，对其**赊销 (credit sales)** 采用了**备抵法 (allowance method)**。会计师通知会计经理，应根据销售净额百分比法，计提 20,000 美元的潜在坏账。此外，两周后，公司得知一名客户因破产无法支付 3,000 美元的欠款，因此需要**核销 (write off)** 这笔坏账。请为计提坏账费用和核销客户无法支付的余额这两项业务编制会计分录。

首先，在确认销售的同期，我们需要确认相应的**坏账费用 (Bad Debt Expense)**，并将这笔金额计入一个备用账户，以备未来实际发生坏账时使用。根据上一课的内容，我们知道应该借记“坏账费用”，贷记“坏账准备”。因此，第一笔分录是：

> 借：**坏账费用 (Bad Debt Expense)** 20,000 美元
> 贷：**坏账准备 (Allowance for Bad Debt)** 20,000 美元

两周后，我们发现一位客户因破产无法支付 3,000 美元。此时，我们收回这笔钱的可能性很低。虽然在破产程序中，我们仍有可能收回部分款项，或者通过谈判达成某种协议，但目前来看，我们预计无法收回这笔钱。因此，我们需要核销该客户的全部**应收账款 (Accounts Receivable, AR)** 余额。为此，我们需要从之前计提的“坏账准备”中扣除这笔金额，并冲销相应的应收账款。具体分录如下：

> 借：**坏账准备 (Allowance for Bad Debt)** 3,000 美元
> 贷：**应收账款 (Accounts Receivable)** 3,000 美元

完成这笔分录后，该客户在我们账上的应收账款余额就变为零了。不过，我们仍然会保留这笔记录。如果该客户未来再与我们交易，我们可能会要求其先付清之前的 3,000 美元欠款。当然，如果这笔债务在破产程序中被法院正式免除，我们就不能再追讨。届时，我们会将其视为一个新客户，并在未来的交易中采取更谨慎的信用政策，例如要求“现款现货 (cash on demand)”，不再提供任何信用额度。

这是一个关于坏账处理的简单示例。虽然本课直接给出了具体数字，但关键在于理解这两笔核心的会计分录。掌握了这些基础，我们才能在后续课程中学习更复杂的内容，例如如何计算并估算出 20,000 美元这个坏账准备的金额。
