## 应收票据案例讲解

本节课我们将通过一个具体的案例，完整地讲解应收票据 (Notes Receivable) 的各个会计处理阶段，包括上一节课我们讨论过的利息计算。

A 公司发生了以下几项交易，我们需要为所有这些交易编制相应的日记账分录 (Journal Entry)。

---

### A. 票据的签发

**交易 A：** 20X1年7月1日，A 公司向一家供应商出借 25,000 美元，对方签署了一张为期一年、年利率为 7.5% 的票据。

**分析与分录：**

此时，公司付出现金，并获得一张未来可以收款的票据。

-   公司支付了 25,000 美元的现金 (Cash)，现金是资产，资产减少应记为贷方 (Credit)。
-   作为交换，公司得到了一张应收票据，这是一项资产，代表未来收款的权利。资产增加应记为借方 (Debit)。

因此，在 20X1年7月1日，我们记录以下分录：

| 日期 | 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- | :--- |
| 20X1/7/1 | 应收票据 (Notes Receivable) | $25,000 | |
| | 现金 (Cash) | | $25,000 |
| | *（记录票据的签发）* | | |

---

### B. 年末计提利息

**交易 B：** 20X1年12月31日，计提 (Accrue) 该票据的应计利息。

**分析与分录：**

这张票据是从7月1日开始计息的。到年底12月31日，时间已经过去了六个月（7月、8月、9月、10月、11月、12月）。根据权责发生制，尽管我们还没有收到现金，但我们已经赚取了这六个月的利息收入，因此必须在当期确认。

利息的计算公式为：**本金 (Principal) × 利率 (Rate) × 时间 (Time)**

-   **本金**：$25,000
-   **年利率**：7.5% (0.075)
-   **时间**：6个月，即 6/12 年

**应计利息** = $25,000 × 0.075 × (6 / 12) = $937.50

这笔 $937.50 的利息是我们已经赚得但尚未收到的，因此它构成了我们的应收利息 (Interest Receivable) 和利息收入 (Interest Revenue)。

因此，在 20X1年12月31日，我们记录以下调整分录：

| 日期 | 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- | :--- |
| 20X1/12/31 | 应收利息 (Interest Receivable) | $937.50 | |
| | 利息收入 (Interest Revenue) | | $937.50 |
| | *（计提20X1年度的应计利息）* | | |

---

### C. 票据利息的收取

**交易 C：** 20X2年7月1日，收到该票据的利息。

**分析与分录：**

在票据到期日，我们收到了整整一年的利息。我们需要处理以下三件事：
1.  确认收到的现金总额。
2.  核销去年年底确认的应收利息。
3.  确认本年度（20X2年）赚取的利息收入。

首先，计算我们收到的现金总额，即一整年的利息：
**总利息** = $25,000 × 0.075 × (12 / 12) = $1,875

这 1,875 美元中：
-   $937.50 是去年（20X1年）的利息，我们已经将其记录为“应收利息”。现在收到了现金，需要将这个应收项核销。
-   另外 $937.50 是今年（20X2年1月1日至7月1日）这六个月产生的利息，应确认为当期的“利息收入”。

因此，在 20X2年7月1日，我们记录以下分录：

| 日期 | 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- | :--- |
| 20X2/7/1 | 现金 (Cash) | $1,875.00 | |
| | 应收利息 (Interest Receivable) | | $937.50 |
| | 利息收入 (Interest Revenue) | | $937.50 |
| | *（收到全年利息并确认当期收入）* | | |

---

### D. 票据本金的收回

**交易 D：** 20X2年7月1日，收到票据本金。

**分析与分录：**

在票据到期日，除了利息，我们还会收回最初借出的 25,000 美元本金。

-   公司收到 25,000 美元现金，现金资产增加，记为借方。
-   应收票据这项资产已经兑现，因此需要核销，资产减少记为贷方。

这实际上是最初签发票据时分录的冲销。

因此，在 20X2年7月1日，我们记录以下分录：

| 日期 | 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- | :--- |
| 20X2/7/1 | 现金 (Cash) | $25,000 | |
| | 应收票据 (Notes Receivable) | | $25,000 |
| | *（记录票据本金的收回）* | | |

---

### 总结

通过以上步骤，我们完整地展示了应收票据从签发、计提利息、收取利息到最终收回本金的全生命周期的会计处理。希望这个案例能帮助你更好地理解相关日记账分录的编制。
