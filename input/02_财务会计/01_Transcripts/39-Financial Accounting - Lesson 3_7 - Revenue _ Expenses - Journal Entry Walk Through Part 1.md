# 财务会计 - 3.7 - 收入与费用 - 日记账分录实例讲解（一）

## 日记账分录 (Journal Entry) 格式回顾

在开始学习收入与费用的交易分录前，我们先回顾一下**日记账分录 (Journal Entry)** 的基本格式和规则。

一个标准的日记账分录包含账户名称、**借方 (Debit)** 和 **贷方 (Credit)** 金额。记录时遵循以下规则：
- **账户名称**记录在左侧。
- **借方**账户写在前面，并且顶格书写。
- **贷方**账户写在借方账户下方，并向右缩进，以示区分。
- 借方金额填入借方栏，贷方金额填入贷方栏。对于一个只有一借一贷的简单分录，六个单元格中通常只有四个会被填写。

进行日记账分录时，必须遵守以下核心原则：
1.  **有借必有贷**：每笔分录都必须同时包含借方和贷方，这是**复式记账法 (Double-entry Accounting)** 的基础。
2.  **借贷必相等**：所有借方账户的总金额必须等于所有贷方账户的总金额。即使是包含多个借方或贷方账户的**复合分录 (Compound Journal Entry)**，这条规则也必须遵守。
3.  **格式规范**：请务必将贷方账户名进行缩进。虽然数字填写在正确的栏目中很重要，但规范的格式能让分录一目了然，避免混淆。

## 实例一：提供服务并立即收到现金

**情景**：在四月份，Walnut Creek 公司提供了总计 7,500 美元的租赁服务。客户没有预付款，而是在每天使用完场地后支付当天的费用。所有款项都直接存入了公司的银行账户。

**分析**：
- **交易本质**：公司提供了服务（使用场地），并立即收到了现金。
- **涉及账户**：公司收到了**现金 (Cash)**，同时赚取了**服务收入 (Service Revenue)**。
- **账户分类**：
    - **现金 (Cash)** 是**资产 (Asset)**。
    - **服务收入 (Service Revenue)** 是**收入 (Revenue)**。
- **账户变化**：
    - 收到现金，公司资产增加。
    - 提供了服务，公司收入增加。
- **应用借贷规则**：
    - 资产增加，记为**借方 (Debit)**。
    - 收入增加，记为**贷方 (Credit)**。

**日记账分录**：
| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 现金 (Cash) | 7,500 | |
| &emsp;服务收入 (Service Revenue) | | 7,500 |

> **注意**：通常情况下，名称中带有“收入”的账户都属于收入类。但有两个重要例外：**递延收入 (Deferred Revenue)** 和 **未赚取收入 (Unearned Revenue)**，它们都属于**负债 (Liability)**，因为公司收了钱却还未提供相应的服务或产品。

## 实例二：预收未来服务的定金

**情景**：4月10日，一对新人预订了 Walnut Creek 公司五月份的婚礼场地，并支付了 1,000 美元的定金。

**分析**：
- **交易本质**：公司收到了现金，但作为交换，公司只是承诺在未来（五月）提供场地。由于服务尚未提供，这笔钱不能算作当前收入。
- **涉及账户**：公司收到了**现金 (Cash)**，但这笔钱是预收款，因此产生了一项义务，应记为**递延收入 (Deferred Revenue)**。
- **账户分类**：
    - **现金 (Cash)** 是**资产 (Asset)**。
    - **递延收入 (Deferred Revenue)** 是**负债 (Liability)**，因为它代表了公司未来需要履行的服务义务。
- **账户变化**：
    - 收到现金，公司资产增加。
    - 公司欠客户一项未来的服务，因此负债增加。
- **应用借贷规则**：
    - 资产增加，记为**借方 (Debit)**。
    - 负债增加，记为**贷方 (Credit)**。

**日记账分录**：
| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 现金 (Cash) | 1,000 | |
| &emsp;递延收入 (Deferred Revenue) | | 1,000 |

> 当五月份婚礼实际举行，服务被提供后，公司才会将这笔负债转为收入。届时的分录将是：借记“递延收入”1,000美元，贷记“服务收入”1,000美元。

## 实例三：销售产品并允许赊账

**情景**：Walnut Creek 公司拥有一个橘子园。在收获季末，公司向 Baldwin Superstores 销售了 5,000 磅橘子，总价为 2,500 美元。公司将橘子送达后，向对方开具了**发票 (Invoice)**，付款期限为30天。

**分析**：
- **交易本质**：公司已经交付了产品（橘子），因此收入已经实现。但公司没有收到现金，而是收到了一份未来收款的承诺，即“欠条 (IOU)”。
- **涉及账户**：这份“欠条”在会计上被称为**应收账款 (Accounts Receivable, A/R)**。由于销售的是产品而非服务，我们使用**销售收入 (Sales Revenue)** 账户。
- **账户分类**：
    - **应收账款 (A/R)** 是**资产 (Asset)**，因为它代表了未来收取现金的权利。
    - **销售收入 (Sales Revenue)** 是**收入 (Revenue)**。
- **账户变化**：
    - 公司被欠的钱增加了，因此资产（应收账款）增加。
    - 公司完成了销售，收入增加。
- **应用借贷规则**：
    - 资产增加，记为**借方 (Debit)**。
    - 收入增加，记为**贷方 (Credit)**。

**日记账分录**：
| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 应收账款 (A/R) | 2,500 | |
| &emsp;销售收入 (Sales Revenue) | | 2,500 |

> **提示**：学习日记账分录最有效的方法是多加练习。主动尝试解决问题，而不是被动观看，这样才能真正掌握并提高解题速度。

## 实例四：收到之前赊销的款项

**情景**：Walnut Creek 公司收到了来自 Baldwin Superstores 的一张 2,000 美元支票，用于支付之前购买橘子的部分款项。

**分析**：
- **交易本质**：公司收到了现金，作为交换，公司放弃了向客户追讨这 2,000 美元欠款的权利。
- **重要提示**：此时不能再次记录收入。因为收入在上一笔交易（实例三）中已经确认。如果再次贷记收入，将导致收入被重复计算。
- **涉及账户**：公司收到了**现金 (Cash)**，同时客户所欠的**应收账款 (A/R)** 减少了。
- **账户分类**：
    - **现金 (Cash)** 是**资产 (Asset)**。
    - **应收账款 (A/R)** 也是**资产 (Asset)**。
- **账户变化**：
    - 收到现金，一项资产（现金）增加。
    - 客户的欠款减少，另一项资产（应收账款）减少。
- **应用借贷规则**：
    - 资产（现金）增加，记为**借方 (Debit)**。
    - 资产（应收账款）减少，记为**贷方 (Credit)**。

**日记账分录**：
| 账户 | 借方 (Debit) | 贷方 (Credit) |
| :--- | :--- | :--- |
| 现金 (Cash) | 2,000 | |
| &emsp;应收账款 (A/R) | | 2,000 |

## 总结

通过以上四个例子，我们探讨了收入确认的几种常见情况：
1.  **钱货两清**：在提供服务或产品的同时收到现金。
2.  **预收款**：在提供服务或产品之前收到现金，产生递延收入（负债）。
3.  **赊销**：在提供服务或产品之后才收到现金，产生应收账款（资产）。
4.  **收回欠款**：收到之前赊销的款项，将应收账款转换为现金。
