# 财务会计 - 课程 3.13 - 案例 1 - 现金收付制 vs 权责发生制 - 利润表

在本节课中，我们将通过一个例子来讲解**现金收付制 (Cash Basis)** 与**权责发生制 (Accrual Basis)** 下的**利润表 (Income Statement)**。我们会分析一些交易，并观察每一笔交易如何从现金收付制和权责发生制两个角度影响利润表。请记住，本课程完全基于权责发生制，因为这是更复杂、规则更多的一种方法。现金收付制非常简单，只需追踪现金流即可：现金流入即为**收入 (Revenue)**，现金流出即为**费用 (Expense)**。如果我们只讲现金收付制，可能几个章节前课程就结束了。因为我们学习的不是这种简单的会计方法，所以必须了解现金收付制和权责发生制之间的区别。

---

### 案例背景

**Polar Pop 公司 (Polar Pop Inc.)** 在一月份有以下交易：

1.  售出价值 22,000 美元的音乐活动门票，该活动计划于本月底举行。公司已收取 9,000 美元现金，其余部分为**应收账款 (on account)**。
2.  收到一张 800 美元的广告费账单，将于二月份支付。
3.  支付了本月咨询服务费 450 美元。
4.  为即将举行的活动销售 T 恤，获得 12,000 美元现金收入。所有 T 恤在销售时均已交付给顾客。

**要求**：请分别使用现金收付制和权责发生制为 Polar Pop 公司编制利润表。

---

### 交易分析

我们需要逐一分析这四笔交易，并确定它们在现金收付制和权责发生制下应如何处理。

#### 交易 1：门票销售

> 售出价值 22,000 美元的音乐活动门票，已收取 9,000 美元现金，其余为应收账款。

-   **现金收付制 (Cash Basis)**：此方法只关心实际收到的现金。公司在本月收到了 9,000 美元现金，因此，在现金收付制下，本月的收入为 9,000 美元。
-   **权责发生制 (Accrual Basis)**：此方法要求在提供服务或交付商品后才能确认收入。虽然门票已售出，但音乐活动（即服务）尚未在本月内发生。因此，根据权责发生制，我们尚未“赚得”这笔收入。本月与此交易相关的收入为 0 美元。

#### 交易 2：广告费用

> 收到一张 800 美元的广告费账单，将于二月份支付。

-   **现金收付制 (Cash Basis)**：只有在支付现金时才记录费用。由于这笔款项将在二月支付，一月份没有现金流出，因此在本期，广告费用为 0 美元。
-   **权责发生制 (Accrual Basis)**：当费用实际发生时就应记录，无论是否支付现金。公司已经收到了账单，这意味着广告服务很可能已经在一月份被使用（即费用已**发生 (incurred)**）。因此，我们应在本期记录 800 美元的广告费用。

#### 交易 3：咨询费用

> 支付了本月咨询服务费 450 美元。

-   **现金收付制 (Cash Basis)**：关键词是“支付”。公司支付了 450 美元现金，因此记录 450 美元的费用。
-   **权责发生制 (Accrual Basis)**：这笔费用是“本月”的咨询费，意味着服务已在本期提供，费用已经发生。因此，同样记录 450 美元的费用。在这种情况下，两种方法的处理结果相同。

#### 交易 4：T 恤销售

> 销售 T 恤获得 12,000 美元现金，所有 T 恤在销售时均已交付。

-   **现金收付制 (Cash Basis)**：公司收到了 12,000 美元现金。加上之前门票销售收到的 9,000 美元，本月总现金收入为 9,000 + 12,000 = 21,000 美元。
-   **权责发生制 (Accrual Basis)**：关键词是“已交付”。T 恤已经交付给顾客，意味着公司的**履约义务 (performance obligation)** 已经完成。因此，我们已经“赚得”了这 12,000 美元。由于门票服务的收入为 0，本月总收入为 12,000 美元。

---

### 利润表汇总

现在，我们可以根据以上分析计算两种方法下的**净利润 (Net Income)**。

| 项目 | 现金收付制 (Cash Basis) | 权责发生制 (Accrual Basis) |
| :--- | :--- | :--- |
| **收入 (Revenue)** | | |
| 门票销售 | $9,000 | $0 |
| T 恤销售 | $12,000 | $12,000 |
| **总收入** | **$21,000** | **$12,000** |
| | | |
| **费用 (Expenses)** | | |
| 广告费用 | $0 | $800 |
| 咨询费用 | $450 | $450 |
| **总费用** | **$450** | **$1,250** |
| | | |
| **净利润 (Net Income)** | **$20,550** | **$10,750** |

### 结论

如此例所示，现金收付制下的净利润为 20,550 美元，而权责发生制下为 10,750 美元。两者存在显著差异，这是因为两种会计方法遵循不同的记账规则。当月底的音乐活动实际举行后，权责发生制下的收入将会增加 22,000 美元，届时报表又会呈现出不同的结果。
